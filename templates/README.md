# templates

Шаблоны для повторяющихся форматов: KOL-ответ, аналитическая справка, конспект исследования, слайд-дек, сравнительная таблица.

Шаблоны добавляются по мере появления стабильных форматов — не на пустом месте. Когда вы трижды повторили одну и ту же структуру, имеет смысл закрепить её здесь.
