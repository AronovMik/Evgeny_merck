# Правила построения клинических кейсов для портфеля Конкор

> Контекст для работы в Claude.ai (или другом не-репозиторном окружении). Собран из сессий 2026-05-17 — 2026-05-21 работы над Кейсом 1 Конкор АМ.
>
> **Назначение:** иметь под рукой собранные правила, чтобы не повторять ошибки, выловленные итерациями. Применять как системный контекст / project knowledge при построении новых кейсов.

---

## 1. Контекст препарата и портфеля

**Портфель Merck Russia (кардиология):**
- **Конкор** — бисопролол (β1-селективный адреноблокатор).
- **Конкор АМ** — FDC бисопролол + амлодипин (дозировки: 5/5, 5/10, 10/5, 10/10).
- **Конкор НСТ** — FDC бисопролол + гидрохлортиазид 6,25 мг.
- **Конкор Кор** — отдельный SKU (см. ОХЛП).

**Аудитория:** кардиологи, реже терапевты. Российская практика.

**Рамка гайдлайнов — закон:** КР МЗ РФ. ESC/ESH/AHA/ACC — только справочно, когда КР МЗ РФ не покрывает, с явной маркировкой.

**Стратегическое правило: АГ — фон всех кейсов.** Поскольку показание Конкор АМ по разделу 4.1 ОХЛП — только артериальная гипертензия (как замещение монокомпонентами в тех же дозах), главный пациент каждого кейса должен иметь АГ как первичное или равнозначное основание для применения FDC. Сопутствующие состояния (ИБС, ХСН, ХБП) добавляют клиническую глубину, но не вытесняют АГ как зарегистрированное показание. Off-label дисклеймер при коморбидных популяциях — на уровне презентации (мастер-слайд / общая плашка), не в тексте каждого кейса.

## 2. Конкор АМ — регуляторные ограничения (ОХЛП ЛП-№012650-РГ-RU от 28.11.2025)

### 2.1. Показание (4.1) — ДОСЛОВНО
> «Артериальная гипертензия — замещение терапии монокомпонентными препаратами амлодипина и бисопролола в тех же дозах.»

**Критично:**
- Показание — **только АГ**.
- Только как **switch** с уже подобранной свободной комбинации в **тех же дозах**. Не стартовое назначение.
- Любая работа с АГ + ИБС, АГ + ХСН и т.п. — **за пределами зарегистрированного показания** → обязателен дисклеймер «получены у пациентов с АГ и сопутствующей …» / «в рамках замещения подобранной свободной комбинации монокомпонентов».

### 2.2. Противопоказания (4.3)
- Гиперчувствительность.
- Тяжёлая артериальная гипотензия / симптоматическая гипотензия / шок.
- Нестабильная стенокардия (кроме Принцметала).
- Гемодинамически нестабильная СН после острого ИМ.
- Обструкция выходного отдела ЛЖ (клинически значимый аортальный стеноз).
- Острая СН / ХСН в декомпенсации, требующая инотропов.
- AV-блокада II–III ст. без ЭКС.
- СССУ, синоатриальная блокада.
- **Выраженная брадикардия (ЧСС <60/мин)**.
- **Тяжёлые формы бронхиальной астмы**.
- Выраженные нарушения периферического артериального кровообращения / синдром Рейно.
- Феохромоцитома без одновременной α-блокады.
- Метаболический ацидоз.

### 2.3. С осторожностью (4.4) — клинически значимое
- **ХОБЛ — только тяжёлые формы**; нетяжёлая БА. **Лёгкая ХОБЛ (GOLD 1) — НЕ в «с осторожностью»**.
- ХСН III–IV NYHA (особенно неишемической этиологии — амлодипин может ↑ риск отёка лёгких).
- СД 1 типа / СД с колебаниями гликемии (бисопролол может маскировать тахикардию как признак гипогликемии).
- Гипертиреоз (бисопролол маскирует симптомы).
- Псориаз (β-блокаторы могут обострять).
- AV-блокада I ст.
- Стенокардия Принцметала.
- Острый ИМ (первый месяц), пожилой возраст, аортальный/митральный стеноз, ГКМП обструктивная.
- Общая анестезия — отменять постепенно за ~48 ч.

### 2.4. Доза
- 1 таблетка в день, **утром**, независимо от приёма пищи.
- Не разжёвывать, не делить.
- **Не прекращать резко** (особенно при ИБС — постепенное снижение).
- Пожилые — обычные дозы.
- Тяжёлая ХПН (КК <20) — макс. бисопролола 10 мг.
- Тяжёлая печёночная недостаточность — макс. 10 мг.

### 2.5. Конкор НСТ
- Показание — **только АГ лёгкой и умеренной степени**.
- ИБС / ХСН — **вне показаний** Конкор НСТ.

## 3. Формулировка диагнозов по КР МЗ РФ

### 3.1. Артериальная гипертензия (КР МЗ РФ АГ-2024)

**Правило:**
- **Впервые диагностированная АГ** → указывается **степень** (1 / 2 / 3) по уровню АД.
- **Пациент на АГТ** → степень **НЕ указывается**, фиксируется **«целевой уровень АД достигнут / не достигнут»**.

**Стадии:**
- I — без ПОМ.
- II — есть ПОМ (ГЛЖ, ХБП С1-2 + А1, утолщение интимы-медиа, и т.д.).
- III — есть АКС (ИБС, перенесённый ИМ/ОНМК, ХСН, ХБП ≥С3 или А2-3, СД с ПОМ, и т.д.).

**Риск (4 категории):**
- 1 (низкий), 2 (умеренный/средний), 3 (высокий), 4 (очень высокий).
- Очень высокий — при установленном ССЗ (ИБС, ОНМК, ХСН), СД с ПОМ, ХБП ≥С3, SCORE2 ≥10 (≥7,5% для России).

**Пример (КР МЗ РФ АГ-2024, образец 4):**
> «ИБС. Стенокардия напряжения III ФК. Перенесенный ИМ (2010г). ГБ III стадии. Целевой уровень АД достигнут/не достигнут. Риск 4 (очень высокий).»

**Россия — страна очень высокого риска по SCORE2.** Порог ≥7,5%.

### 3.2. ИБС / стабильная стенокардия (КР МЗ РФ Стабильная ИБС-2024)

**Формат:**
> «ИБС: стабильная стенокардия напряжения ФК X. [Постинфарктный кардиосклероз (год).] [Состояние после ЧКВ с имплантацией СВЛ в [артерию] (год).]»

**Не включать в диагноз:**
- Гемодинамические стенозы по КАГ (это инструментальные данные).
- «Оптимальная медикаментозная терапия» / «ОМТ» (это раздел плана лечения).

**ФК:**
- I — обычная нагрузка не провоцирует, только тяжёлая/быстрая/длительная.
- II — лёгкое ограничение (быстрая ходьба, подъём >1 этажа).
- III — выраженное ограничение (ходьба 100–200 м, подъём 1 этажа).
- IV — невозможна без боли, может быть в покое.

**Целевая ЧСС при стабильной стенокардии:** 55–60 уд/мин (КР МЗ РФ).

### 3.3. ХБП (КР МЗ РФ / KDIGO)

**Формат:** «ХБП СxAy».

- **С1** ≥90; **С2** 60–89; **С3а** 45–59; **С3б** 30–44; **С4** 15–29; **С5** <15 мл/мин/1,73 м².
- **А1** альбумин/креатинин <30 мг/г; **А2** 30–300 (микроальбуминурия); **А3** >300 (макроальбуминурия).

**Требования к диагнозу:** персистенция ≥3 месяца (≥2 измерения). При одной пробе формально диагноз ХБП преждевременен; в кейсах можно либо упомянуть «подтверждено повторно через 3 мес», либо принять как осознанный компромисс.

### 3.4. ХОБЛ (КР МЗ РФ / GOLD)

**Диагноз требует:**
- Постбронходилатационная спирометрия: **ОФВ1/ФЖЕЛ <0,70**.
- Клинический контекст (симптомы, факторы риска — курение).

**GOLD по ОФВ1 (% от должного):** 1 ≥80; 2 50–79; 3 30–49; 4 <30.

**Группа** (по симптомам + обострениям): A / B / E.

### 3.5. Дислипидемия (КР МЗ РФ 2023, тип по Фредриксону)

| Тип | Что повышено | TG | Шифр |
|---|---|---|---|
| **IIa** | ЛНП ↑, ХС ↑ | норма | E78.0 |
| **IIb** | ЛНП + ЛОНП ↑, ХС + TG ↑ | ↑ | E78.2 |
| **IV** | ЛОНП ↑, TG ↑ | ↑ | E78.1 |

**В диагнозе:** «Гиперлипопротеидемия Фредриксона, тип XX (E78.X). Целевой ХС-ЛНП достигнут / не достигнут».

**Целевой ЛНП:**
- Очень высокий риск: **<1,4 ммоль/л** + снижение от исходного ≥50%.
- Высокий риск: <1,8 + ≥50%.
- Умеренный: <2,6.
- Низкий: <3,0.

При ЛНП >2× от целевого + очень высокий риск → допустим **старт с комбинированной липидоснижающей терапии** (статин + эзетимиб).

## 4. Верификация расчётов (обязательно с явной подстановкой)

| Что | Формула | Норма / порог |
|---|---|---|
| Суточный индекс СМАД | (САДдн − САДноч) / САДдн × 100% | 10–20% = диппер; <10% = нон-диппер |
| Ночная гипертензия | САД/ДАД ночью | ≥120/70 мм рт.ст. (КР МЗ РФ АГ-2024) |
| Фридевальд | ЛНП = ОХС − ЛВП − ТГ/2,2 | Не работает при TG >4,5 |
| ИМТ | вес / рост² | 18,5–24,9 норма; 25–29,9 избыток |
| Соколов-Лайон | S(V1) + R(V5 или V6) | ≥35 мм = ГЛЖ |
| ИММЛЖ | масса ЛЖ / ППТ | ≥115 г/м² (М); ≥95 г/м² (Ж) — ГЛЖ |
| СКФ CKD-EPI | по калькулятору | <60 — ХБП (с альбуминурией ≥3 мес) |
| % снижения ЛНП | (исх − финал) / исх × 100% | для очень высокого риска: ≥50% |

**Правило: ни одно число — «по памяти».** Если формулы / клинрека под рукой нет — сообщить пользователю до утверждения.

## 5. Метод vs получаемая информация

- **Характер ритма** (синусовый, ФП, и т.д.) — **только по ЭКГ**. Пальпация даёт «ритмичный / неритмичный / аритмичный пульс».
- **Локальная сократимость / асинергия** — **только по ЭхоКГ**.
- **Ишемия миокарда** — нагрузочная проба (стресс-ЭКГ / стресс-ЭхоКГ / стресс-МРТ / ОФЭКТ) или **КАГ**.
- **Диагноз ХОБЛ vs БА vs ACO** — **пре- и постбронходилатационная** спирометрия с расчётом обратимости. Только постбронходилатационных значений недостаточно: для разведения ХОБЛ vs БА vs asthma-COPD overlap нужен прирост ОФВ1 (значимая обратимость — ≥12% И ≥200 мл = БА или ACO; ниже порога — ХОБЛ без значимой обратимости). У курильщика с симптомами ACO — реальный дифференциальный диагноз.
- **ЭхоКГ описывает СЕГМЕНТЫ СТЕНОК ЛЖ** (17-сегментная модель), а не бассейны артерий. Сначала описание (стенки/сегменты), потом интерпретация (зона, типично кровоснабжаемая X).
- **Микроальбуминурия** — единичное измерение недостаточно для ХБП А2 (нужна повторность ≥3 мес).
- **HbA1c** — **вспомогательный**, не диагностический критерий предиабета по КР МЗ РФ / ВОЗ. Формально предиабет: НГН 6,1–6,9 или НТГ по ПГТТ.

## 6. Структура кейса (4 слайда, по образцу Евгения)

### Слайд 1 — Титул
«Пациент [инициалы], [пол], [возраст].»

### Слайд 2 — Анамнез
- **Жалобы.**
- **Анамнез заболевания** (длительность диагноза, прежняя терапия, недавняя динамика).
- **Текущая терапия.**
- **Анамнез жизни** (профессия, курение в пачка-летах, алкоголь).
- **Факторы риска.**
- **Наследственность** отягощена (если есть).

### Слайд 3 — Обследование
- **Физикальное:** рост/вес/ИМТ; АД (можно с СМАД); ЧСС + ритмичность; тоны, дыхание, отёки.
- **Инструментальное:** ЭКГ покоя; ЭхоКГ покоя; стресс-ЭхоКГ / нагрузочная проба; КАГ при необходимости; спирометрия при стаже курения.
- **Лабораторное:** гликемия + HbA1c; креатинин + СКФ + альбумин/креатинин; липидный профиль; ТТГ при первичном обследовании.
- **Диагноз (КР МЗ РФ):** структура по разделу 3 этого документа.

### Слайд 4 — План лечения
- **Шаг 1.** Что добавлено / на каком основании. Динамика через **1–2 нед** (β-блокаторный эффект на ЧСС и стенокардию виден быстро, ждать 4 нед — нереалистично у симптомного пациента).
- **Шаг 2.** Эскалация / добавление компонента. Динамика через **2–4 нед** (стабилизация эффекта комбинации).
- **Шаг 3.** Перевод на FDC после **2–4 нед стабильности** на свободной комбинации — switch в тех же дозах. Сохраняемая базовая терапия.

**Правило интервалов:** не ставить шаблонные 4 нед на каждый шаг. Реалистично: 2 / 3 / 2–4. Это норма российской поликлинической кардиологической практики у симптомного пациента.
- **Результат терапии:** цели АД, ЧСС, симптомов.
- **Почему Конкор АМ:** USP-блок (см. раздел 7).

## 7. USP-блок Конкор АМ (для слайда 4)

1. **Единственная в РФ FDC бисопролол + амлодипин.**
2. **Switch с двух монокомпонентов в тех же дозах — единственный валидный сценарий по инструкции** (само по себе образовательный месседж).
3. **Упрощение схемы** → повышение приверженности.
4. **Verma AA et al. PLOS Medicine 2018** (ретроспективная когорта, n=13 350 пациентов с АГ, до 5 лет наблюдения): FDC vs свободная комбинация — общая смертность ОР 0,85 (95% ДИ 0,77–0,94; p<0,01), комбинированная конечная точка «смерть, ИМ, СН, инсульт» ОР 0,89 (95% ДИ 0,81–0,97; p<0,01); приверженность 70% vs 42%. **Указывать дизайн (ретроспективная когорта) и популяцию (АГ)** — без экстраполяции.
5. **Кардиоселективность бисопролола** → лёгкая ХОБЛ (GOLD 1) вне ограничений ОХЛП (ни противопоказание, ни «с осторожностью»).

## 8. Регуляторные риски в формулировках

- **Прямые алгоритмы дозирования** в активной форме («титруем до целевой ЧСС 55–60») — медпред воспроизводить **не может**. Атрибуция: «по решению лечащего врача» / референс на КР МЗ РФ как сноска, не как алгоритм.
- **Off-label популяция** (за пределами раздела 4.1 ОХЛП) — требует **явного дисклеймера** в тексте, не только в комментариях.
- **Прямые сравнения с конкурентами** — только при наличии прямого RCT; иначе запрещены.
- **«Допустим при …», «можно при …»** в активной форме — слабее, чем привязка к инструкции («по ОХЛП ограничения касаются только тяжёлых форм; лёгкая степень не входит в меры предосторожности»).

## 9. Типовые ошибки (антипаттерны, выловленные итерациями)

- **Non-dipper / dipper без подсчёта суточного индекса.** Считать арифметически до использования ярлыка.
- **«Синусовый ритм» в физикальном осмотре** (только ЭКГ может это утверждать). Пишите «ритмичный пульс».
- **«Оптимальная медикаментозная терапия» в строке диагноза ИБС.** Не часть формального диагноза.
- **Степень АГ у пациента на терапии.** Не указывается; фиксируется «цель достигнута/не достигнута».
- **Альбумин/креатинин без повторности.** Формально не верифицирует ХБП А2 за одно измерение — либо обозначить как осознанный компромисс, либо упомянуть повторность через 3 мес.
- **ЛНП >2× от цели + старт только статина без эзетимиба.** Аторвастатин 40 мг даст ~45% снижения — не дотянет до цели <1,4 при исходном 3,8. Старт с комбинации обоснован.
- **Описание ЭхоКГ через бассейны артерий** вместо сегментов стенок ЛЖ. Связь сегмент-артерия — переменная по типу кровоснабжения.
- **Финальное АД 120/76 у пациента со значимым стенозом + non-dipper-паттерном** — провоцирует дискуссию о J-кривой. Целевой коридор по КР МЗ РФ — 120–130/70–80 при ИБС; держаться в коридоре, не у нижней границы.
- **USP «упрощение схемы — 2 таблетки вместо 3»** в одиночку — слишком бытовой аргумент для специалиста. Усиливать через приверженность + твёрдые конечные точки (Verma 2018) + FDC = гарантированная доза каждого компонента.
- **«Допустим при ХОБЛ лёгкой степени»** в активной форме — лучше: «по ОХЛП лёгкая ХОБЛ не входит ни в противопоказания, ни в "с осторожностью"».
- **ХОБЛ-диагноз без указания постбронходилатационной спирометрии** — оставляет лазейку «диагноз не верифицирован по GOLD».
- **ХОБЛ без теста обратимости** — не разводит ХОБЛ vs БА vs asthma-COPD overlap. Обязательно пре- и пост-значения + прирост ОФВ1 явно ниже 12% и 200 мл.
- **Шаблонные 4 нед на каждый шаг** — нереалистично для симптомного пациента. Реалистично: Шаг 1 — 1–2 нед, Шаг 2 — 2–4 нед, Шаг 3 — после 2–4 нед стабильности.
- **Дислипидемия без типа по Фредриксону** — теряется регуляторная привязка (E78.0 при IIa).

## 10. Источники (для верификации фактов)

**Российские:**
- КР МЗ РФ 2024. **Артериальная гипертензия у взрослых.**
- КР МЗ РФ 2024. **Стабильная ишемическая болезнь сердца.**
- КР МЗ РФ 2024. **Хроническая сердечная недостаточность.**
- КР МЗ РФ 2023. **Нарушения липидного обмена.**

**Инструкции:**
- ОХЛП Конкор АМ (ЛП-№012650-РГ-RU от 28.11.2025).

## 11. Чек-лист перед финализацией кейса

- [ ] Диагноз АГ: степень только при впервые диагностированной; иначе «цель достигнута/не достигнута».
- [ ] Диагноз ИБС: без стенозов и «ОМТ» в строке диагноза.
- [ ] Диагноз ХБП: С + А, с учётом персистенции или с явным комментарием.
- [ ] Диагноз ХОБЛ: GOLD стадия, группа A/B/E, спирометрия постбронходилатационная.
- [ ] Диагноз дислипидемии: тип по Фредриксону, шифр E78.X.
- [ ] СМАД: суточный индекс посчитан арифметически; ночное АД ≥120/70 → «ночная гипертензия» отдельно.
- [ ] Фридевальд: TC, HDL, TG, LDL согласованы.
- [ ] Физикальный осмотр: «синусовый» только в ЭКГ-блоке; в осмотре «ритмичный пульс».
- [ ] ЭхоКГ: сегменты стенок ЛЖ, не бассейны артерий.
- [ ] Стенокардия: цель ЧСС 55–60 (КР МЗ РФ).
- [ ] Финальное АД: в коридоре 120–130/70–80 (не у нижней границы у пациента с ИБС).
- [ ] Старт статин-терапии: если ЛНП >2× от цели + очень высокий риск — комбинация.
- [ ] Switch на Конкор АМ: явный нарратив «стабилизирован на свободной комбинации → switch в тех же дозах».
- [ ] USP-блок: единственная FDC + switch как USP + упрощение + Verma 2018 + ХОБЛ.
- [ ] Если популяция за пределами 4.1 ОХЛП (АГ + ИБС/ХСН) — явный off-label дисклеймер.
- [ ] Целевая ЧСС / АД на слайде — со ссылкой на КР МЗ РФ, не как личная цель.
- [ ] Прямые алгоритмы дозирования — с атрибуцией «по решению лечащего врача».
- [ ] АГ — фон кейса; пациент всегда имеет АГ как основание для применения FDC.
- [ ] Спирометрия: пре- и пост-значения + явный расчёт обратимости.
- [ ] Интервалы между шагами реалистичные: 1–2 / 2–4 / 2–4 нед, не шаблонные 4.
