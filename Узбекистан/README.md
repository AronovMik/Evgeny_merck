## Назначение

Разбор цикловой книги Конкор® H2/2026 для рынка Узбекистана. Методология и формат — те же, что в `Казахстан/`: построчная сверка утверждений книги с регуляторными документами и первоисточниками, комментарии в телеграфном формате для отправки продукт-менеджеру.

---

## Регуляторная рамка — критический пробел

**В репозитории нет ни одного узбекского документа.** Ни инструкции по медицинскому применению (ИМП РУз) на Конкор, ни национальных клинических протоколов или стандартов МЗ РУз.

Это хуже, чем ситуация с Казахстаном, где есть хотя бы КП МЗ РК по АГ (`Казахстан/MZ-RK_2026_hypertension-adults_protocol-253.pdf`).

**Следствие для всех выводов по Узбекистану:**

- проверка показаний, противопоказаний, дозировок и состава идёт по **российскому ОХЛП** (`context/product-info/konkor/`) с обязательной пометкой «требует сверки с РУз»;
- граница off-label в Узбекистане может отличаться от российской;
- статус регистрации Конкор Кор 2,5 мг в РУз неизвестен, хотя книга ссылается на него как на инструмент титрации;
- утверждения о показаниях **конкурентов** (небиволол, карведилол, метопролол) также не проверяемы — узбекских инструкций на них нет.

## Что нужно загрузить

- [ ] ИМП РУз на Конкор® (и на Конкор Кор, если зарегистрирован)
- [ ] Национальный клинический протокол / стандарт МЗ РУз по артериальной гипертензии
- [ ] То же по ИБС и по ХСН
- [ ] ИМП РУз на небиволол — для проверки блока сравнения (слайды 16–18)
- [ ] Публикация исследования **CREATIVE** — цитируется на слайде 34, не идентифицирована

## Конфиденциальность

Сама цикловая книга в репозиторий **не загружается** — внутренний коммерческий документ, репозиторий публичный. Из разбора исключены: размер базы врачей и аптек, пороги сегментации по потенциалу и лояльности, ФИО сотрудников и лекторов, даты и площадки мероприятий. Приводятся только клинические, регуляторные и научные формулировки, необходимые для существа разбора.
