Вердикт председателя

Где совет соглашается. Маршрут A технически валиден по ОХЛП; switch в тех же дозах корректен; HFA-PEFF набран правильно; дапаглифлозин обоснован как disease-modifying при HFpEF.
Где совет расходится. Голос распределился: A (НЕТ) / B (с 4 правками) / C (без изменений). Peer review единогласно (3/3) — C самое большое слепое пятно: назвал HbA1c 5,6% «жёстким аргументом», Жернакову не оспорил. 2/3 reviewers — B самый сильный; 1/3 — A.
Слепые пятна peer review.
  • Интервалы между шагами не указаны.
  • HbA1c 5,6% при активном СД2 — возможная ремиссия (по ВОЗ/ADA HbA1c <6,5% без сахароснижающей = ремиссия).
  • Дозы амлодипина и дапаглифлозина при ХБП С2А2 не оговорены (формально ОК, но молчание).
КРИТИЧНО — без этого кейс не выходит:
  1. Жернакова 2017 — ограничить клейм «у пациентов с АГ и МС» + механистическая база β1-селективности; либо удалить пункт USP в текущей форме.
  2. HbA1c 5,6% при СД2 — либо изменить на 6,5% (типичный для компенсированного), либо явно прописать «в стадии медикаментозной компенсации».
ВАЖНО — для устойчивости:
  1. Шаг 2 — переписать атрибуцию: «на фоне комплексной терапии (Конкор 10 + амлодипин 5)».
  2. ЧСС 86 на Конкор Кор 2,5 — добавить строку в анамнез: «назначен в стационаре после ИМ 2023; амбулаторная титрация не проводилась».
  3. HFpEF-дисклеймер: «ББ для контроля ЧСС и постинфарктной протекции; disease-modifying для ХСНсФВ — только иНГЛТ2».
  4. Fair balance: «риск маскировки гипогликемии низкий — дапаглифлозин не вызывает гипогликемии, метформин — низкий потенциал».
  5. Интервалы: Шаг 1 — 2–3 нед; Шаг 2 — 3–4 нед; Шаг 3 — после 2–4 нед стабильности.
Опционально: ЛНП 1,77 не достигнута — добавить «дальнейшая интенсификация липидоснижающей терапии по решению лечащего врача».
Сделать первым: Решить Жернакову 2017 + HbA1c 5,6%. Эти два пункта определяют каркас СД2-нарратива; всё остальное косметика рядом с ними.

Ответы участников

Кардиолог 1 (за) — ПРИНЯТЬ безоговорочно
Кейс клинически связный, маршрут обоснован, фокус на СД2-нейтральности востребован. Архетип типичен. Построчные находки в пользу: - АД 155/95, ЧСС 86 на Конкор Кор 2,5 — точка старта убедительная. - HFA-PEFF 5 корректен. - HbA1c 5,6% — жёсткое обоснование низкого риска; fair balance декоративный. - Дапаглифлозин — disease-modifying при HFpEF (IА). - Конкор 10 → ЧСС ~58 — Чесникова 2014 подтверждает. - Switch на Конкор АМ 10/5 — ОХЛП-валидный. Итог: принять без изменений.
Кардиолог 2 (против) — НЕ ПРИНЯТЬ (3 структурных дефекта)
Построчные находки: - «ГБ III стадии» без уточнения «цель достигнута/не достигнута» — режет глаз. - ЧСС 86 на Конкор Кор 2,5 — не пояснено, почему пациент пришёл с такой ЧСС. - HbA1c 5,6% при СД2 — нормогликемия, не «целевая при СД2» (цель <7,0 или <6,5). Либо ремиссия (требует упоминания), либо реальный показатель — тогда disease-modifying роль дапаглифлозина ослабевает. - Жернакова 2017 (n=30, МС, НЕ СД2) — экстраполяция недопустима для центрального USP. - ЛНП 1,77 при ПИКС+СД2 → цель <1,4 не достигнута; следующий шаг не указан. FQ-уязвимости: №5 (evidence-claim, главная); №3 (off-label Конкор Кор у HFpEF); №6 (fair balance без источника). Итог: до устранения Жернаковой, статуса СД2, объяснения ЧСС 86 — не принимать.
Маркетолог Merck — ПРИНЯТЬ с 4 правками
Регуляторно-маркетинговые находки: - Жернакова 2017 — критический риск: МС, не СД2, n=30. Альтернатива: ограничить клейм «у пациентов с МС» + механистические данные β1-селективности. - Конкор Кор 2,5 → HFpEF — off-label умеренный; нужен дисклеймер по disease-modifying. - Шаг 2: Конкор 5→10 → ФК I — прогностический overclaim: атрибуция дозе при одновременном добавлении амлодипина. - ЧСС 55-60 + СД2 — общая форма fair balance; нужен акцент HbA1c 5,6% + иНГЛТ2. USP №4 (СД2-нейтральность) наиболее уязвим compliance. 4 правки — Жернакова, HFpEF-дисклеймер, разделить атрибуцию, усилить fair balance.

Peer review (A = Кардиолог 2, B = Маркетолог Merck, C = Кардиолог 1)

1. Самый сильный — B. Совмещает клинические находки с регуляторно-маркетинговой логикой. Жернакова — «незащитимая экстраполяция»; идентифицирует overclaim атрибуции ФК II→I; предлагает альтернативу для USP. Вердикт «с правками» операционно полезен. 2. Слепое пятно — C. Reviewer 2 — самый сильный B, слепое пятно C, упустили: совместимость HbA1c с СД2
1. Самый сильный — B. Сбалансированно взвесил находки, точно идентифицировал главные риски, предложил конкретные правки. 2. Слепое пятно — C. Если ремиссия — обоснование USP меняется.

1. Самый сильный — A. Жёсткое НЕТ с обоснованными стоп-факторами: Жернакова, нераскрытый статус СД2, необъяснённая ЧСС 86. Структура «диагноз → порог». 2. Слепое пятно — C. Принял без изменений, проигнорировал недостижение ЛНП <1,4 при ПИКС+СД2. 3. Упустили все: дозы амлодипина и дапаглифлозина при ХБП С2А2 не оговорены. «ГБ III стадии» при достигнутом АД 130/80 на момент switch — формальная пометка по КР МЗ РФ.
