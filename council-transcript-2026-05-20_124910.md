## Шаг 1. Ответы участников

### Кардиолог 1 (за) — ПРИНЯТЬ безоговорочно

Кейс v5 клинически валиден и готов к использованию.

Стратегическое обоснование: единственный валидный сценарий применения Конкор АМ по инструкции — switch с двух монокомпонентов в тех же дозах после стабилизации. Логика трёх шагов безупречна. Архетип узнаваем.

Построчная проверка — что особенно сильное:
- Стресс-ЭхоКГ как метод верификации ишемии — корректно: гипокинез средних и апикальных сегментов передней и переднеперегородочной стенок ЛЖ при ЧСС 130 соответствует зоне стеноза ПНА 70%.
- Характер ритма — только по ЭКГ: «синусовый ритм» в ЭКГ покоя, пульс описан как «ритмичный, удовлетворительного наполнения» — без атрибуции характера. Принцип №7 соблюдён.
- ХОБЛ верифицирован постбронходилатационной спирометрией (ОФВ1/ФЖЕЛ 0,66 < 0,70).
- ХБП С2 А2 — стадирование верное по обоим критериям.
- ИММЛЖ 124 г/м² > 115 (порог ГЛЖ у мужчин).
- Диагноз АГ — без степени, через «целевой АД не достигнут», по образцу КР МЗ РФ.
- Switch на Конкор АМ — дозы идентичны, единственное условие инструкции выполнено.
- Кашель типичен для ХОБЛ, иАПФ в схеме нет — внутренняя согласованность сохранена.

Итог: кейс прошёл построчную проверку без клинических ошибок. Принимаем без доработки.

### Кардиолог 2 (против) — НЕ ПРИНЯТЬ

Два принципиальных дефекта.

Построчные находки:
1. **СМАД** — «нормальное ночное снижение; ночная гипертензия» — логическое противоречие в одной строке без связки. Редакционная небрежность.
2. ХОБЛ — корректно верифицирован, замечание снято.
3. ИМТ 27,14 → 27,1 — допустимая погрешность.
4. **ХБП С2А2** — единственное измерение альбуминурии без подтверждения повторно через ≥3 мес. Формально диагноз А2 по КР МЗ РФ не верифицирован.
5. **На Шаге 2 уже полный контроль** (АД 125/77, ЧСС 62, приступов нет) — зачем Шаг 3? Переключение на FDC при достигнутой цели обосновано только приверженностью — слабый нарратив. Аудитория спросит: «вы меняете схему у стабильного пациента ради удобства упаковки?»

Стратегические возражения: Verma 2018 — ретроспективная когорта, бисо+амло не выделены отдельно. Использование как прямого доказательства для Конкор АМ методологически уязвимо.

Итог: до устранения противоречия в СМАД и неверифицированной ХБП А2 — не выносить.

### Маркетолог Merck — ПРИНЯТЬ с 2 правками

Регуляторно-маркетинговые находки:
- **Шаг 1–2: «Конкор увеличен с 5 до 10 мг по динамике ЧСС»** — прямая инструкция по титрации; медпред не имеет права воспроизводить как самостоятельную рекомендацию. Нужна атрибуция: «решение лечащего врача».
- **USP «Единственная в РФ FDC бисо+амло»** — регуляторно чисто; требует верификации актуальности реестра ГРЛС перед каждым использованием.
- **USP «Допустим при ХОБЛ GOLD 1»** — потенциальный off-label риск: ХОБЛ в инструкции — «применять с осторожностью» без градации по GOLD. Нужна ремарка: «по решению врача при лёгкой обструкции, с мониторингом функции внешнего дыхания» + ссылка на инструкцию.
- **Verma 2018:** популяция АГ без обязательной ИБС/ХОБЛ; экстраполяция на нашего пациента формально не валидирована. Медпред должен быть обучен не расширять вывод.

USP-блок v5 значительно усилен. Три кита работают: уникальность FDC, упрощение схемы (2 вместо 3), численные значения Verma. Для российского кардиолога эмоционально убедителен.

Итог: принять с двумя правками — атрибуция титрации, смягчение ХОБЛ-допустимости.
