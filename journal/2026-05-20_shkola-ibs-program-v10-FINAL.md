# 2026-05-20 — Школа ИБС: программа v1.0 (финальная)

## Что сделано

Доведена программа Школы ИБС от рабочих итераций v0.5 → v1.0 (финал). Файл: `tasks/slides/2026-05-20_shkola-ibs_programma_v10_FINAL.docx`.

## Цепочка решений в этой сессии

1. **v0.5 → v0.6:** добавлен мини-перерыв 10 мин внутри Части 1 (раздел Гражданкина 90 мин трудно тянуть подряд); добавлен «слайд-мостик» 2-я → Часть 3 для Кашталапа.
2. **v0.6 → v0.7:** мини-перерыв зафиксирован **после блока 1.3** (граница «концепция / методы»: 1.1–1.3 = от симптомов через ПТВ к стратегии; 1.4–1.6 = CAC / стресс-методы / реваскуляризация). Часть 3 расширена с 45 до 50 мин за счёт сокращения второй паузы до 5 мин. Введён 4-й кейс по гипердиагностике (асимптомный + CAC = 280 → ошибочное назначение БАБ+АК).
3. **v0.7 → v0.8:** Евгений снял кейс по гипердиагностике («формулировка непонятная, уведёт дискуссию в сторону: что ещё было кроме CAC и т.д.»). Заменён на **grey zone реваскуляризации**: пациентка с уже сделанными стресс-визуализацией и КАГ, вопрос «нужен ли стент». Закрывает прямой запрос аудитории.
4. **v0.8 → v0.9:** Евгений предложил две важные правки кейса 4:
   - Заменить стресс-ЭхоКГ на **СПЭКТ-перфузию миокарда с нагрузкой** (там корректно считается прирост ишемии в % ЛЖ; на стресс-ЭхоКГ — нет).
   - Однососудистое поражение → **двухсосудистое** (стенозы 65% ОА + 60% ПКА), но **в чистой grey zone**: без LM, без прокс. ПНА, без дисфункции ЛЖ (ЕФ 60%), без СД, объём ишемии <10% — Class I прогностических показаний не выполняется. Тактика B → C (FFR → интенсификация ОМТ).
5. **v0.9 → v1.0 (финал):** аудит таймингов, устранение расхождений:
   - Часть 2.6 расширена с 2 до 4 мин (Часть 2 теперь точно 50 мин).
   - Конфликт «закрытие 4 мин внутри Части 3» vs «Сводное закрытие дня 5 мин в таблице» устранён: внутри Части 3 — 4-минутный буфер на голосования и переходы; отдельное «Сводное закрытие дня» — 5 мин (18:55–19:00).
   - Добавлен блок **«Контроль таймингов — карточка модератора»** с поминутной разбивкой каждого подблока.
   - Добавлен короткий блок **«Ключевые решения этой версии»** в начале документа.
   - Проверена сумма: 5 + 50 + 10 + 50 + 15 + 50 + 5 + 50 + 5 = 240 минут ✓.
