### Карточка деки (`*.md`)

Из заготовки превращена в полноценный навигационный хаб. Что в ней:
- Метаданные + перечень артефактов с описанием назначения каждого.
- Три темы лекций, под которые дек собирается (rationale §1).
- Структура 14 секций с главными тезисами блоков (rationale §3, §9).
- **«Указатель: где что лежит»** — таблица «если задача про X — смотреть слайды Y, заметки Z». Это основное, ради чего Евгений просил завести библиотеку: чтобы я при будущих задачах мог быстро подсказывать готовые блоки.
- Регуляторные правила: дисклеймер «получены у» (с явным правильным/неправильным вариантом), список удалённых слайдов с причинами (чтобы не возвращать без обоснования).
- Рамка гайдлайнов (ESC 2024 CCS + Hypertension, КР МЗ РФ 2024 АГ + стабильная ИБС).
- Ключевые источники (список без отдельных полных карточек — они в самой PPTX).
- Слабые точки источников + заранее заготовленные линии ответа эксперту (rationale §11).
- Терминология (HR→ОР, FDC оставлено, и т. д.) + открытая задача по унификации.
- 8 открытых задач (rationale §14), синхронизированы с TODO.md.

## Решения
- **Переименование под более общую тему** (`fdc-bisop-amlo` вместо `stable-angina-htn-fdc-transition`) — потому что финальное название деки про FDC в широком смысле, а stable-angina — только одна из трёх лекционных конфигураций. `git mv` использован для сохранения истории файлов.
- **Извлечь скрипт в MD дополнительно к DOCX** — чтобы скрипт был greppable, виден в git diffs, и доступен следующей Claude-сессии без обязательного извлечения. DOCX остаётся для редактирования в Word.
- **Rationale положен дословно**, без переписывания — это первичный документ Евгения, его не редактируем, чтобы не потерять оттенки.
- **Принципы построения деки вынесены в `decisions/`**, а не оставлены внутри карточки деки — они шире одной деки и должны переноситься на новые проекты.
- **Карточка деки построена вокруг таблицы «где что лежит»** — это рабочий инструмент для подсказок при новых задачах, главное, что я буду использовать при будущих обращениях.
