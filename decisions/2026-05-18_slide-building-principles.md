# Методологические принципы построения слайдсетов

**Дата:** 2026-05-18
**Статус:** принято
**Источник:** работа над декой Конкор® АМ v2.0 (см. карточку `context/slide-library/2026-05-14_konkor-am_fdc-bisop-amlo_v2.0.md` и rationale рядом).

## Контекст
В мае 2026 завершена работа над крупным слайдсетом Конкор® АМ v2.0 (97 слайдов, 14 секций). В процессе выработаны методологические правила, которые относятся не только к этой деке, а **ко всем будущим презентационным материалам** Евгения. Чтобы не открывать заново и не терять на новых проектах — фиксируем как общий стандарт репозитория.

## Принципы (применять при подготовке любых новых слайдсетов)

1. **Слайд = одно исследование.** Не сшивать данные из разных публикаций в один слайд — это создаёт риск cherry-picking и делает невозможным корректный методологический дисклеймер. Исключение допускается только для сводных таблиц с явно обозначенным дизайном каждой строки.

2. **Заголовок-вывод, не заголовок-описание.** Заголовок слайда должен содержать главный тезис слайда, а не нейтральное описание исследования. Плохо: «Применение фиксированной комбинации… приводит к…». Хорошо: «Конкор® АМ при АГ и ИБС: 96,7% достижение целевого АД».

3. **Подзаголовок с дизайном / популяцией / N — но не для маленьких выборок (n<30).** Чтобы не акцентировать слабость. Дизайн читается на самом слайде через дисклеймер.

4. **Дисклеймер «получены у» — обязателен на off-label слайдах.** Формула:
   - ✅ «Препарат X зарегистрирован для лечения Y. Данные получены у пациентов с Y и сопутствующей Z.»
   - ❌ «Данные применимы для пациентов с Y и Z.»

   Вторая формула = off-label promotion риск. Перед публичным использованием — согласование с юристами/комплаенс компании.

5. **При отсутствии межгруппового p — не утверждать «значимо превосходит».** В заголовке — нейтральное «снижение», «улучшение», цифры говорят сами. Методологическую оговорку обязательно проговаривать в скрипте, не уходить от неё.

6. **Не возвращать удалённые слайды без явного нового обоснования.** Все удаления были по существенным причинам — методологическим, регуляторным или из-за дублирования. Возвращать только при появлении новых данных, снимающих исходную причину.

7. **Регуляторные риски выше эстетики и маркетинга.**
   - Сравнительная реклама ЛС (ФЗ «О рекламе» ст. 24) — особо аккуратно: конкретные побочные эффекты, приписанные «всем дженерикам», = повод для жалобы конкурента в ФАС.
   - Формулировки типа «уникальная технология», «шелковистость поверхности» без доказательной поддержки — не для medical affairs.

8. **При противоречивых данных — обе позиции, без выбора «победителя».** Если запрошен однозначный вывод — с оговоркой об уровне неопределённости. Отозванные / Expression of Concern источники — упоминаются «в обратном ключе», как опровергаемое.

9. **Слайды-резюме блоков обязательны** для блоков >1 слайда. Стандартный формат: маркер «Главное из блока» в правом верхнем углу + крупный центральный тезис (≤25 слов, самодостаточный, без оценочных слов без оснований) + 2–4 опорных буллета + источники. Тезис должен быть процитируем вне контекста.

10. **Принцип «меню для эксперта» для крупных деков.** Один общий дек из тематических блоков, из которого собираются конфигурации под конкретную лекцию или вопрос. Альтернатива «три отдельных дека под три лекции» отвергнута: дублирование контента → проблема обновлений; каждый дек короче, но не покрывает побочные вопросы.

## Дополнительно: версионность и сохранность

- В имени файла деки — версия `vX.Y` и **дата последней правки** (не загрузки).
- Старые версии **не удаляются** — лежат рядом, чтобы видеть эволюцию.
- Рядом с каждым PPTX — MD-карточка (навигационный хаб) + по возможности rationale (почему так сделано) + скрипт (что говорить). Карточка читается первой, PPTX открывается только при явной необходимости.

## Слабые точки источников — фиксировать в карточке деки

Каждая известная слабость источника записывается в карточку деки **с заранее подготовленной линией ответа эксперту**. Не для того чтобы скрыть, а чтобы лектор знал, как ответить, когда вопрос придёт. Это сильно снижает риск «провала» в дискуссии.

## Терминология

- Заменять английские аббревиатуры на русские там, где это не имена собственные и не общепринятые в международной литературе термины (HR→ОР, OR→ОШ, RR→ОР, 95% CI→95% ДИ, mmHg→мм рт. ст.).
- **HR ≠ OR ≠ RR** — типичная путаница; критическая. Проверять каждое употребление.
- **FDC оставлять** (с расшифровкой), потому что «ФК» в кардиологии часто означает «функциональный класс».

## Что это значит для будущих ревизий и новых дек

Если через год появляется новое исследование или новый гайдлайн:
- Проверить, согласуется ли с принципом 1 → создать **новый слайд**, не дописать на существующий.
- Проверить регистрационный статус → если off-label популяция, дисклеймер «получены у».
- Проверить место в архитектуре → к какому блоку относится; нужно ли обновить главный тезис блока в слайде-резюме.
- Если заменяется источник → проверить, не теряется ли важный аргумент; обновить раздел «Ключевые источники» в карточке.

При создании **новой деки по другому препарату** — применять те же принципы по умолчанию, отклонения обосновывать явно.
