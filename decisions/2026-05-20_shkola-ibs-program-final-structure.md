# Решение: финальная структура программы Школы ИБС (17 июня 2026)

**Дата принятия:** 2026-05-20
**Статус:** утверждено для согласования с Кашталапом и Гражданкиным

## Контекст

Школа ИБС — образовательный день для кардиологов 17 июня 2026, 15:00–19:00 (4 часа). Два эксперта: Гражданкин (диагностика), Кашталап (терапия). Стратегический фокус Merck — продвижение Конкор АМ через клинически обоснованную траекторию «стенокардия + АГ → 10 мг бисопролола → switch на фиксированную комбинацию».

## Решение

Зафиксирована структура дня в файле `tasks/slides/2026-05-20_shkola-ibs_programma_v10_FINAL.docx`:

1. **Длительность ровно 240 минут** (5+50+10+50+15+50+5+50+5).
2. **Часть 1 разделена на 1A + 1B** по 50 мин с мини-перерывом 10 мин **после блока 1.3** (граница «концепция → методы»). Логика: 1.1–1.3 = от симптомов через ПТВ к стратегии (концептуальная половина); 1.4–1.6 = CAC, стресс-методы, реваскуляризация (техническая половина). Естественная когнитивная развилка.
3. **Часть 2 — 50 мин** с двумя интерактивами (после слайда отмены БАБ и после блока Конкор АМ). **Оба интерактива инициирует сам Кашталап**, обращаясь к Гражданкину — это создаёт ощущение живого диалога, а не «модератор передаёт слово».
4. **Блок 2.5 — открывающий слайд = таблица частот коморбидов** у пациентов с ИБС, а не описательный «портрет коморбидного пациента». Источники — КР МЗ РФ + российские RWE-регистры; финальный выбор регистров за Кашталапом.
5. **Часть 3 — 4 кейса**:
   - Кейс 1 (13 мин): АГ → впервые стенокардия → ОМТ → Конкор АМ;
   - Кейс 2 (13 мин): субклинический атеросклероз → CAC → верификация ИБС → Конкор АМ + липиды;
   - Кейс 3 (13 мин): high-risk ишемия → ЧКВ → пожизненная ОМТ с Конкор АМ;
   - Кейс 4 (7 мин, grey zone): двухсосудистое поражение без LM/прокс. ПНА, объём ишемии <10% по СПЭКТ-перфузии, FFR не делался — нужна ли реваскуляризация. Закрывает прямой запрос аудитории на «проблемные» развилки в показаниях к ЧКВ.
   - +4 мин буфер на голосования.
6. **Сводное закрытие — отдельным блоком 5 мин** (не внутри Части 3): голосование «что измените с понедельника» + по 1–2 мин финальных тезисов от каждого эксперта.

## Обоснование выбора Кейса 4 (grey zone)

Альтернатива — кейс по гипердиагностике (асимптомный + CAC = 280 → ошибочное назначение БАБ+АК) — отклонена, так как формулировка непонятная и уводит дискуссию в сторону («что ещё было кроме CAC?»).

Текущая версия кейса 4 (двухсосудистое + <10% ишемии + без FFR) — типичная развилка из ежедневной практики кардиолога; иллюстрирует:
- принцип «стеноз ≠ показание к реваскуляризации» (КР МЗ РФ 2024 / ESC 2024 CCS Class I);
- обязательность FFR/iFR для стенозов 50–90% без явной зоны ишемии;
- линию ISCHEMIA / ORBITA / FAME-2: hard outcomes vs symptomatic relief vs FFR-guided ЧКВ;
- логичную тактику B → C (FFR обоих сосудов → интенсификация ОМТ при FFR>0,80).

## Что НЕ вошло в финал и почему

- **Отдельные 30 мин Q&A после Части 1** — невозможно при 4-часовом дне; компромисс — интегрированный Q&A в финале блока 1.6 (5 мин) + мини-перерыв 10 мин после 1.3.
- **«Пациентский» блок** — снят на этапе v0.2: школа адресована профессиональной аудитории, упор на врачебные решения.
- **Конкор НСТ** — упомянут в блоке 2.4 одной строкой; в основном фокусе текущей школы не разбирается (тема следующей школы).

## Последствия

- Кашталап готовит к школе: дополнительный слайд по дозе 10 мг, слайд по безопасной отмене БАБ, слайд по СД2, чек-лист по коморбидностям, таблица частот коморбидов для блока 2.5.
- Гражданкин: возможные правки по PDF (бины CAC, таблица ПТВ — 4 vs 3 категории, расхождения КР РФ vs ESC) — отдельный документ «Замечания к PDF Гражданкина» в работе.
- Все интерактивы в Части 2 — без отдельных слайдов; Кашталап ведёт их по готовности.
