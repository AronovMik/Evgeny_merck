# Система логирования: STATE + TODO + journal + ideas + decisions

**Дата:** 2026-05-17
**Статус:** принято

## Контекст
Евгений работает с Claude через разные чаты и сессии. При переходе из одного чата в другой контекст теряется. Нужна структура, по которой любой новый чат (или новая сессия Claude Code) мгновенно понимает: над чем работаем, где остановились, какие решения уже приняты.

## Рассмотренные варианты
1. **Только `CLAUDE.md`** — минимально, но не масштабируется: один файл не вместит и состояние, и идеи, и историю решений.
2. **Один большой `CONTEXT.md`** — проще, но смешивает живое состояние с историческими решениями и идеями, быстро становится нечитаемым.
3. **Многоуровневая система** (принято) — разделение по природе записи: живой снапшот / список задач / хронология / поток идей / принятые решения.

## Принятое решение
Пять отдельных каналов записи:

| Файл / папка | Назначение | Когда обновляется |
|---|---|---|
| `STATE.md` | Живой снапшот: что в фокусе, последние решения, точка возврата | В конце каждой сессии Claude, при крупных изменениях |
| `TODO.md` | Глобальный список задач: Active / Backlog / Done | При появлении/закрытии задачи |
| `journal/` | Хронологический лог сессий: контекст → сделано → решения → следующий шаг | В конце каждой непустой сессии |
| `ideas/INBOX.md` | Сырой поток идей, append-only; вырастает в отдельные файлы по мере созревания | По мере возникновения мысли |
| `decisions/` | Стабильные принятые решения с обоснованием; история не удаляется | При принятии нового принципиального решения |

## Workflow в начале сессии
1. Прочитать `STATE.md`.
2. Прочитать последнюю запись в `journal/`.
3. Заглянуть в `TODO.md` (Active).
4. Дальше работать по запросу пользователя.

## Workflow в конце сессии
1. Обновить `STATE.md` (что в фокусе, точка возврата).
2. Добавить запись в `journal/YYYY-MM-DD_*.md` (если сессия была непустой).
3. Если появились новые задачи — записать в `TODO.md`.
4. Если приняли крупное решение — создать файл в `decisions/`.
5. Закоммитить.

## Последствия
- В `CLAUDE.md` зафиксированы правила «читать STATE.md в начале сессии, обновлять в конце».
- При переходе Евгения в новый чат достаточно показать Claude этот репозиторий — контекст подхватится автоматически.
- Возможное будущее улучшение: SessionStart-хук в `.claude/settings.json` для автоматической инжекции `STATE.md` в каждую сессию (см. `ideas/INBOX.md`).
