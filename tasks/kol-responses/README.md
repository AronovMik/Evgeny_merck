# tasks/kol-responses

Ответы на медицинские запросы от KOL и врачей. Формальные, с полной верификацией источников.

**Структура файла:**
1. Вопрос (дословно, как поступил).
2. Контекст KOL (специальность, регион, ранее обсуждавшиеся темы — если релевантно).
3. Ответ.
4. Ссылки (PMID/DOI, каждый источник — отдельной строкой).
5. Off-label/непрямые сравнения — маркировать в самом тексте ответа.

**Чеклист научной верификации обязателен** (Блок 3 INSTRUCTIONS.md).
