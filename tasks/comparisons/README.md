# tasks/comparisons

Сравнительные таблицы препаратов, head-to-head данные, сетевые метаанализы.

**Важно** (Блок 5.4 INSTRUCTIONS.md): прямые сравнения — только при наличии head-to-head РКИ или NMA. Все непрямые сравнения **явно маркировать** как непрямые в самой таблице, не только в комментарии.

**Структура файла:**
1. Сравниваемые препараты (МНН, дозы, показания, по которым идёт сравнение).
2. Тип сравнения: head-to-head РКИ / NMA / нарративный обзор / непрямое.
3. Таблица сравнения.
4. Источники по каждой ячейке.
5. Ограничения сравнения (различия популяций, конечных точек, доз).
