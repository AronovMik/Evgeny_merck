# tasks/letters

Письма: ответы KOL по почте, внутренние коммуникации в Merck, письма врачам по запросам, переписка по исследовательским вопросам.

**Формат файла:** `YYYY-MM-DD_адресат_тема.md`. В шапке указывать адресата, контекст переписки, ожидаемый тон.

**Не путать с** `kol-responses/` — там полные ответы на формальные медицинские запросы.
