# tasks/scientific-texts

Научные тексты: абстракты, обзоры, сообщения для научных журналов, материалы для научных мероприятий, рукописи.

**Чеклист научной верификации обязателен** (Блок 3 INSTRUCTIONS.md).

**Структура файла:**
1. Целевое издание/мероприятие, формат, объём, дедлайн.
2. Soavtor(ы), если применимо.
3. Текст черновика.
4. Список ссылок (формат под целевой журнал).
5. Заметки по версиям/правкам.
