# tasks/slides

Слайды и презентации: для KOL-встреч, advisory boards, внутренних обсуждений, внешних научных мероприятий.

**Формат файла задачи:** `YYYY-MM-DD_препарат_тема.md` с структурированным планом презентации (заголовок слайда → ключевые тезисы → источники).

**Чеклист перед финализацией:** Блок 3 (научная верификация) + Блок 5 (fair balance, off-label, портфельный контекст) из `INSTRUCTIONS.md`.
