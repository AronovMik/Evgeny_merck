# КЕЙС 2. Атипичная картина у коморбидной пациентки (13 мин)

Финальный текстовый вариант слайдов для вставки в Word-файл программы.
Соответствует pptx-версии (5 слайдов).

---

## СЛАЙД 1 — Клинический случай 2 (профиль пациентки)

Женщина 64 года.

АГ ≥6 лет на рамиприле 5 мг + амлодипине 5 мг. АД во время осмотра 138/84, ЧСС 78.

СД 2 типа: HbA1c 7,2%, на метформине + эмпаглифлозине.

Дислипидемия: ЛНП 3,4 ммоль/л на аторвастатине 20 мг.

Нет установленного диагноза ИБС.

Пришла на приём для пересмотра гиполипидемической терапии. При активном расспросе: ≥6 мес — одышка при подъёме на 3-й этаж и быстрой ходьбе, проходит в покое за 3–5 мин; несколько раз снимала короткодействующими нитратами.

Факторы риска:
- Дислипидемия (ЛНП 3,4 ммоль/л);
- Артериальная гипертензия;
- Сахарный диабет.

На слайде: Таблица ПА3-2 КР МЗ РФ «Стабильная ИБС» 2024. Для женщины 60–69, колонка «Одышка при нагрузке» = 14%. Категория — низкая (5–15%).

---

## СЛАЙД 2 — Оценка ПТВ по ESC 2024 RF-CL (Figure 4)

Лектор кратко проговаривает классификацию: основной симптом — одышка, не боль. По КР МЗ РФ одышка — эквивалент стенокардии; таблица ПА3-2 содержит отдельную колонку «Одышка при нагрузке». Расчёт по ESC — через симптом-балл за одышку.

Параметры пациентки:
- Симптом-балл = 2 (одышка как основной симптом).
- Число факторов риска = 3 (АГ + СД2 + дислипидемия).
- Возраст / пол: женщина 60–69.

Результат: ПТВ по ESC RF-CL = 6% → категория «Низкая».

Сверка с КР МЗ РФ (таблица ПА3-2): 14% — категория «Низкая» (5–15%).

Категория совпадает по обоим документам. ESC RF-CL даёт более консервативную цифру у женщин — это намеренный эффект модели («down-classifies more individuals to low likelihood», §3.2.1 ESC 2024). Пациентка находится в нижней части «низкой» зоны, близко к порогу «очень низкой» (≤5%).

## СЛАЙД 3 — Голосование 1

Какой следующий шаг диагностики?

(а) Стресс-визуализация.

(б) МСКТ-коронарография.

(в) Коронарный кальций (CAC) как фильтр-этап перед стресс-тестом.

(г) Сразу инвазивная коронароангиография.

**Правильный ответ:** Особенность ситуации: у пациентки низкая ПТВ + факторы, повышающие её (СД2, АГ, дислипидемия) → формально допустимы три стратегии первой линии, не одна.

(а) Стресс-ЭхоКГ:
- КР МЗ РФ: Класс I C при низкой ПТВ + факторах, повышающих ПТВ (наш случай).
- ESC 2024: при ПТВ 6% (низкая) — Class I B только для >15–85%.
- Минус: при отрицательном результате — не закрывает атеросклероз как таковой, только ишемию.

(б) МСКТ-коронарография:
- КР МЗ РФ: Класс IIa C — при ПТВ ≤15% как первый специфический метод при невозможности стресс-теста.
- ESC 2024: Класс I A для диапазона >5–50%. Сильнейший тест для исключения (NPV >95%).

(в) Коронарный кальций как первый шаг — рациональный выбор:
- ESC 2024: Класс IIa B при низкой вероятности для потенциальной реклассификации.
- КР МЗ РФ: формально не «фильтр-этап», но CAC — официальный модификатор ПТВ (Класс I C).
- При CAC = 0 — стресс-тест можно отложить; при кальцинозе — обоснование к стресс-ЭхоКГ.

(г) Сразу КАГ:
- Нет показаний: нет рефрактерной стенокардии, нет тяжёлой симптоматики покоя, нет данных о высоком риске событий. По КР МЗ РФ и ESC — инвазивная КАГ не оправдана.

## СЛАЙД 4 — Результат диагностики и Голосование 2

Коронарный кальций = 302 → подтверждает выраженный атеросклероз → повышает посттестовую вероятность обструктивной ИБС → стресс-визуализация обоснована как следующий шаг.

Стресс-ЭхоКГ: на 5-й минуте теста при дозе добутамина 20 мкг/кг/мин — индуцируемый гипокинез 2 сегментов в бассейне ПКА + воспроизведённый эквивалент симптомов (одышка).

Диагноз ИБС, стенокардия напряжения ФК II (одышка как эквивалент) — верифицирован.

Голосование 2: дальнейшая тактика?

(а) Направить на КАГ?

(б) Начать ОМТ?

**Правильный ответ: (б) ОМТ как первая стратегия при подтверждённой ишемии умеренного риска (2 сегмента).**

По КР МЗ РФ «Стабильная ИБС» 2024 (Таблица ПА3-4 «Критерии риска ССО по данным диагностических тестов»):
- Низкий риск: НЛС нет или <2 сегментов.
- Умеренный риск: 2 и более сегмента ЛЖ с новыми НЛС.
- Высокий риск: 3 и более сегмента ЛЖ с новыми НЛС (акинезией или гипокинезией); коронарный резерв в ПНА <2,0.

ESC 2024 (Recommendation Table, Класс I B): high risk = ≥3 из 16 сегментов с индуцированной гипо- или акинезией.

КР МЗ РФ имеет более детальную 3-уровневую стратификацию; ESC — фактически 2-уровневую (high / non-high).

КАГ — при недостижении ОМТ-целей через 3–6 месяцев.

## СЛАЙД 5 — Терапия: пошаговый переход на фиксированную комбинацию

Шаг 1 (день 0): добавить бисопролол 2,5 мг к существующей схеме (рамиприл 5 + амлодипин 5); переход на высокоинтенсивный режим статина, при необходимости + эзетимиб; старт АСК 75–100 мг/сут. Метформин и эмпаглифлозин продолжаются без изменений.

Шаг 2 (5–7 дней): повысить бисопролол до 5 мг по переносимости — высокая β1-селективность не ухудшает гликемический контроль и не маскирует гипогликемию.

Шаг 3 (7–14 дней): при необходимости повысить бисопролол до 10 мг (с целью достижения ФК I и целевой ЧСС 55–60); амлодипин — до 10 мг при недостижении АД <130/80.

Шаг 4 (при подборе доз): перевод на фиксированную комбинацию бисопролола и амлодипина (Конкор АМ 5/5, 5/10, 10/5 или 10/10).

Курсивом на слайде, цитата КР МЗ РФ «Стабильная ИБС» 2024:
«У всех пациентов с ИБС целесообразно оценивать эффективность назначенного лечения в ближайшее время (через 3–5 дней) и через 2–4 нед. после начала терапии для проведения в случае необходимости её дальнейшей коррекции. Оценку эффективности терапии следует проводить по частоте приступов стенокардии в неделю, по потребности в приёме короткодействующих нитратов, по расстоянию, которое проходит пациент до появления приступов стенокардии или по его возможности подъёма по лестнице. Для этого следует рекомендовать пациентам ведение дневников самочувствия. В ряде случаев целесообразно проводить нагрузочный тест для оценки изменения ТФН.» — ЕОК I B (УУР С, УДД 5).

При сохраняющихся симптомах — рассмотреть необходимость проведения КАГ; параллельно рассмотреть иные механизмы / причины стенокардии.
