# tasks/analyses

Аналитические справки: разбор отдельных исследований, оценка новых данных, ландшафтный анализ, разбор guidelines.

**Структура файла:**
1. Цель анализа (для кого, под какое решение).
2. Источники.
3. Краткое резюме (TL;DR в 3–5 пунктах).
4. Детальный разбор по чеклисту Блока 3 INSTRUCTIONS.md.
5. Ограничения и неопределённости.
6. Выводы в пределах данных.
