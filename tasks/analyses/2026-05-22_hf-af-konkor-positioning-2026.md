# 2026-05-22 — Konkor positioning slide: HF + AF (2-block "now vs 2026")

> Аналитика и итоговые формулировки для слайда из двух блоков (левый = текущий статус по клинрекам, правый = приоритеты 2026). Цитирование — **только МЗ РФ** (РКО). Слайд EN. До 5 буллетов в блок, предельно короткие.

## Задача
Левый блок: текущий статус Конкора / β-блокаторов в клинреках по ХСН и ФП/ТП.
Правый блок: над чем работаем в следующем году.

## Ключевые корректировки исходных гипотез

1. **HFpEF в РКО 2024 ХСН — это НЕ "IIb как в HFmrEF"**, а более тонкая позиция:
   - β-АБ при синусовом ритме — **IIb B** для снижения госпитализаций (§3.1.9)
   - **«Пациентам с ХСНсФВ β-АБ могут быть назначены при наличии дополнительных показаний»** — дословная цитата комментария §3.1.9
   - **«У пациентов с ФП β-АБ, по всей видимости, неэффективны»** — дословная цитата комментария §3.1.9
   - Это значит, что концепция «approved indications» для HFpEF — **уже официальная позиция МЗ РФ**, не наша интерпретация.

2. **ФП в РКО 2024 ХСН §3.1.6.3** даёт строгую базу для контроля ЧСС:
   - β-АБ — первая линия Class IIa B у пациентов с ХСН I-III ФК в эуволемии
   - Дигоксин — IIa B как добавка / альтернатива при невозможности β-АБ
   - Верапамил/дилтиазем — Class III C при ХСНнФВ
   - Комментарий РКО: «у пациентов с ХСН и ФП β-АБ не улучшают прогноз по сравнению с другими препаратами, контролирующими ЧСЖ» (отсылка к RATE-AF)

3. **КР МЗ РФ по ФП** в библиотеке отсутствует. Формулировка «BB + дигоксин + верапамил при ФВ>40%; BB + дигоксин при ФВ<40%» — стандартная схема ESC AF / КР МЗ РФ по ФП, которую Евгений знает и сам процитирует.

4. **Конкор и показание «ФП»**: в ОХЛП **ни одного** препарата портфеля (Конкор, Конкор АМ, Конкор Кор, Конкор НСТ) показания «фибрилляция предсердий» нет. Бисопролол присутствует в текстах клинреков (включая упоминание RATE-AF), но при ФП как primary target это off-label.

## RATE-AF — главная угроза в нарративе AF

Открытый trial у пожилых с persistent AF + симптомами HF (большинство HFpEF): **бисопролол vs дигоксин**:
- 6 мес: одинаковый rate control и QOL
- 12 мес: **дигоксин лучше** по функциональной способности и ↓NT-proBNP; у бисопролола — больше головокружения, слабости, гипотензии

Этот результат отражён в комментарии РКО 2024 ХСН §3.1.6.3 («β-АБ не улучшают прогноз vs другие препараты, контролирующие ЧСЖ»). В 2026 это будет аргумент конкурентов — нужна проактивная контр-нарративная подача.

## ИТОГОВЫЕ ФОРМУЛИРОВКИ ДЛЯ СЛАЙДА (EN)

### LEFT BLOCK — Where we stand today

> *Per RF MoH HF CPG 2024 (RKO; J Russ Cardiol 2024;29(11)) and RF MoH AF CPG*

1. **HFrEF (LVEF ≤40%):** β-blocker — **Class I**, GDMT cornerstone
2. **HFmrEF (41–49%):** β-blocker — **Class IIb C** (carry-over from HFrEF GDMT)
3. **HFpEF (≥50%, sinus rhythm):** β-blocker — **Class IIb B**; *"only with additional indications"* (RF HF CPG §3.1.9, verbatim)
4. **HFpEF + AF:** β-blockers *"apparently ineffective"* (RF HF CPG §3.1.9, comment)
5. **AF + HF rate control:** β-blocker first-line — **Class IIa B** (§3.1.6.3); **"AF" is not an SmPC indication for any Konkor product**

### RIGHT BLOCK — Where we focus next year

1. **HFpEF — drive phenotype-based positioning**, anchored to RF CPG *"additional indications"* wording
2. **HFmrEF — defend β-blocker within the 4-pillar GDMT carry-over** (Class IIb is a growth signal)
3. **AF — anchor rate-control narrative to approved comorbidities** (AH / stable angina / HF); avoid AF-as-primary (off-label)
4. **Pre-empt the "β-blockers ineffective in AF" line** — reframe via β1-selectivity + value when AF coexists with AH/IHD
5. **Reinforce HF titration story** (Konkor Kor 1.25 mg → Konkor 10 mg, in line with RF HF CPG §3.1.6.3 first-line β-blocker call)

### Альтернативы пункта 5 правого блока (если titration уже надоел)
- Build HFmrEF-specific β-blocker evidence agenda (support IIb → IIa upgrade in next CPG revision)
- Position Konkor as the β1-selective default for HF/AF patients with coexistent COPD (PACE 2026 data)
- Re-anchor AF rate-control messaging on RF AF CPG split by LVEF (>40% bucket = Konkor's SmPC overlap zone via AH)
