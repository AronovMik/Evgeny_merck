# outputs — структурированное извлечение из корпуса «Бета-блокаторы в психиатрии»

Результат задачи структурированного извлечения данных из 10 первоисточников. Никакого текста обзора, никаких выводов о преимуществе препаратов, никаких объяснений расхождений между исследованиями — только извлечённые данные с атрибуцией.

**Корпус:** `context/key-studies/psychiatry/` (10 файлов, лежат в `main`).

## Состав

| Файл | Что внутри |
|---|---|
| `00_ФАЗА-0_инвентаризация.md` | Инвентаризация корпуса: перечни A / B / C, недостающие супплементы с DOI, расхождения с ожидаемым списком |
| `01_сквозной-поиск_бисопролол-и-липофильность.md` | Сквозной поиск по всем 10 файлам: упоминания бисопролола, классификации липофильности, утверждения о ГЭБ |
| `cards/` | 10 карточек Фаз 1–2, по одной на источник: полная карта исследования + ответы на целевые вопросы |
| `master_matrix.tsv` | 10 источников × 8 полей |
| `depression_evidence.tsv` | 21 строка по исходу «депрессия»; колонка различий заполнена только фактами дизайна |
| `bisoprolol_specific.tsv` | 92 факта о бисопрололе, каждый с полной атрибуцией (раздел / таблица / страница) |
| `lipophilicity_classification.tsv` | 10 источников: к какой категории отнесён бисопролол и на что ссылаются авторы |
| `gaps.md` | Недостающие супплементы, фрагментарные источники, позиции «требует визуальной проверки», внутренние противоречия источников, противоречия между источниками, незакрытые вопросы |

## Условные обозначения в файлах

- `НЕ НАЙДЕНО В ФАЙЛЕ` — параметра в источнике физически нет. Не выведено, не реконструировано, не подставлено.
- `ТОЛЬКО В СУППЛЕМЕНТЕ — НЕ ПРИЛОЖЕН` — значение существует, но в предоставленном файле его нет.
- `ТРЕБУЕТ ВИЗУАЛЬНОЙ ПРОВЕРКИ` — данные находятся на рисунке или лес-плоте; числа не извлекались.
- `[осн. текст]` / `[абстракт]` / `[супплемент]` — тип источника значения.

## Три вещи, которые нужно знать до использования этих файлов

1. **Ни к одной статье корпуса не приложен супплемент.** Из-за этого не закрыт ключевой вопрос — эффект и 95% ДИ по бисопрололу в Rasmussen/Holt 2026 (Suppl. Table S3A) и в Molero 2023 (S2 Fig / S2 Table). Список того, что надо докачать, с DOI — в `gaps.md`, п. 1.
2. **Исход «депрессия» операционализирован в пяти источниках пятью несовместимыми способами** — от «только выкупленный рецепт на антидепрессант» до «балл шкалы HADS-D». `gaps.md`, п. 5.2.
3. **Липофильность бисопролола классифицирована в корпусе четырьмя взаимоисключающими способами** (высокая / низкая-гидрофильный / умеренная / смешанная). `gaps.md`, п. 5.1.
