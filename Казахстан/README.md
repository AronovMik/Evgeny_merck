# Казахстан — материалы проекта «Анализ циклового задания_Казахстан»

> Рабочая папка сессии `claude/cyclic-task-analysis-kazakhstan-hbhp7d`.
> Назначение — собрать в одном месте казахстанскую регуляторную и промо-рамку, отличную от российской, и вести по ней анализ циклового задания H2/2026 по Конкор®.

**Создана:** 2026-08-10

---

## Почему отдельная папка

Основной репозиторий построен на **российской** регуляторной рамке: `context/guidelines/` — это КР МЗ РФ / РКО, `context/product-info/` — российские ОХЛП портфеля Конкор. Для Казахстана рамка **другая**: свои клинические протоколы МЗ РК и своя инструкция по медицинскому применению (ИМП РК). Показания, зарегистрированные дозировки и, следовательно, **граница off-label в РК могут не совпадать с РФ**.

Правило для всех задач по этому проекту: **источник истины по Казахстану — документы из этой папки**, а не российские файлы из `context/`. Российские материалы можно привлекать как справочные, но с явной пометкой источника.

## Содержимое

### `MZ-RK_2026_hypertension-adults_protocol-253.pdf`
**Клинический протокол диагностики и лечения «Артериальная гипертензия у взрослых»**, Республика Казахстан.

- **Статус:** одобрен Объединённой комиссией по качеству медицинских услуг МЗ РК, протокол №253 от 10 июня 2026 г.
- **История редакций:** разработан 2015 → 2019 → пересмотр 2024/2026.
- **Объём:** 65 страниц.
- **Коды:** МКБ-10 (I10–I15) и МКБ-11 (BA00–BA04).
- **Статус документа:** публичный нормативный документ МЗ РК.

**Что важно для проекта.** Это тот самый «новый КП МЗ РК по ведению пациентов с АГ от 2026 года», актуализация которого заявлена в целях циклового задания H2/2026. Ключевые для портфеля места:
- β-АБ входят в **пять основных классов** антигипертензивных препаратов наряду с ИАПФ, БРА, БКК и тиазидными/тиазидоподобными диуретиками (IA).
- Бисопролол указан в перечне кардиоселективных β-АБ в диапазоне доз **2,5–10 мг**.
- В перечне фиксированных комбинаций присутствуют **бисопролол + амлодипин** (5/5, 10/5, 5/10, 10/10 мг), **бисопролол + диуретик**, **бисопролол + периндоприл** (5/5, 5/10, 10/5, 10/10 мг).
- Отдельный раздел — клинические ситуации, в которых **добавление β-АБ предпочтительно** на любом этапе терапии.
- Раздел по коморбидности: АГ + ИБС со стенокардией, АГ + ХСН, АГ + ФП (β-АБ — предпочтительный класс для контроля ЧСС при ФП), периоперационный период.

**Рамка использования.** По аналогии с `context/guidelines/INDEX.md`: КП МЗ РК — **основная рамка для казахстанских задач**; ESC/ESH и КР МЗ РФ привлекаются только с явной маркировкой источника, расхождения фиксируются, а не разрешаются «в пользу победителя».

## Чего в папке пока нет (пробелы рамки)

- [ ] **ИМП РК (инструкция по медицинскому применению) на Конкор®** и другие препараты портфеля, зарегистрированные в Казахстане. Без неё нельзя корректно проверять цикловое задание на off-label: раздел показаний РК может отличаться от российского ОХЛП.
- [ ] **КП МЗ РК по ИБС / хроническому коронарному синдрому** — цикловое задание опирается на профиль «АГ + ИБС».
- [ ] **КП МЗ РК по ХСН** — цикловое задание опирается на профиль «АГ + ХСН» и на титрацию до целевой дозы.
- [ ] Состав портфеля Конкор, **зарегистрированный именно в РК** (какие из Конкор / Конкор АМ / Конкор Кор / Конкор НСТ присутствуют на рынке РК и в каких дозировках).

Пока эти документы не загружены, любые выводы по off-label и по соответствию показаниям делаются **на российской рамке с явной пометкой «требует сверки с РК»**.
