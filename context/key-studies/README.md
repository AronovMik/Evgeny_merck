# context/key-studies

Ключевые публикации по бисопрололу и портфелю. Желательно — оригинальные PDF + краткие MD-конспекты по чеклисту Блока 3 INSTRUCTIONS.md.

**Конвенция именования:** `{акроним}_{журнал}_{год}.{ext}` или для конспекта `{акроним}_summary.md`. Примеры:
- `CIBIS-II_Lancet_1999.pdf`
- `CIBIS-II_summary.md`
- `CIBIS-III_Circulation_2005.pdf`
- `BISOMET_summary.md`

**Каждый конспект должен включать:** дизайн, популяцию, интервенцию, конечные точки (с составом композитных), результаты с 95% CI, ограничения, профиль безопасности.
