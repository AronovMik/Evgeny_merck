# superseded/ — устаревшие (замещённые) редакции клинических рекомендаций

> **Это НЕ источник истины.** Папка хранит исторические редакции гайдлайнов, заменённые более новыми версиями. Актуальные документы — в родительской папке `context/guidelines/` и в основной библиотеке (main).

## Политика использования (обязательно)

1. **По умолчанию НЕ использовать.** Источник для задач — актуальные редакции и КР МЗ РФ (см. `CLAUDE.md`, Правило 5).
2. **Использовать только при явной необходимости**, например:
   - спикер/автор ссылается на конкретную старую редакцию, и нужно выверить, что именно там написано;
   - нужно показать эволюцию позиции («было в 2019 → стало в 2024»).
3. **Всегда маркировать в выводе.** Если факт берётся отсюда — в тексте/слайде явно писать, что это **устаревшая (superseded) редакция**, с указанием, чем заменена. Нельзя подавать положение из этой папки как действующую рекомендацию.
4. **При расхождении** со свежей редакцией приоритет всегда у актуального документа; старую версию приводить только с пометкой «в редакции N года было…».

## Заметка по проверке (ESC 2019 CCS)

Сверка искомой фразы «Реваскуляризация миокарда для облегчения симптомов… и вероятно для улучшения прогноза… при проксимальном поражении ПНА / ПКА (правый тип) / ОА (левый тип)»: **дословно этой формулировки в ESC 2019 CCS нет.** Собственный критерий высокого риска ESC 2019 — «Three-vessel disease with proximal stenoses, LM disease, or proximal anterior descending disease»; слово *dominant* употреблено только применительно к микрососудистой дисфункции. Детальные показания к реваскуляризации ESC 2019 CCS **отсылает к ESC/EACTS 2018 Myocardial Revascularization Guidelines** — вероятный первоисточник формулировки с «типом кровотока».
