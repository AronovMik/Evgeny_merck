# context/guidelines

Клинические рекомендации в виде PDF/MD/конспектов: ESC, AHA/ACC, ESH, РКО и др.

> Сводный перечень файлов с темами/годами/источниками: [`INDEX.md`](./INDEX.md).

**Конвенция именования:** `{организация}_{год}_{тема}.{ext}`. Примеры:
- `ESC_2024_hypertension.pdf`
- `ESH_2023_hypertension_summary.md`
- `RKO_2024_chronic-HF.pdf`

**Рекомендуется**: для каждого крупного guideline хранить рядом краткий MD-конспект ключевых положений по бисопрололу (классы рекомендаций, целевые дозы, противопоказания) — `{организация}_{год}_{тема}_summary.md`.
