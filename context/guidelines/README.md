# context/guidelines

Клинические рекомендации в виде PDF/MD/конспектов: ESC, AHA/ACC, ESH, РКО и др.

**Конвенция именования:** `{организация}_{тема}_{год}.{ext}`. Примеры:
- `ESC_2024_hypertension.pdf`
- `ESH_2023_hypertension_summary.md`
- `RKO_2024_HFrEF.pdf`

**Рекомендуется**: для каждого крупного guideline хранить рядом краткий MD-конспект ключевых положений по бисопрололу (классы рекомендаций, целевые дозы, противопоказания).
