# context/product-info

Регуляторные документы портфеля бисопролола Merck Russia: ОХЛП (SmPC), инструкции по применению РФ, локальные брендовые сообщения, утверждённые сравнения.

## Структура — по подпапке на препарат

- `konkor/` — **Конкор** (бисопролол моно, 5 / 10 мг). Показания: АГ, стабильная стенокардия, ХСН.
- `konkor-am/` — **Конкор АМ** (бисопролол + амлодипин, 4 дозировки: 5+5, 5+10, 10+5, 10+10). Показание: АГ.
- `konkor-kor/` — **Конкор Кор** (бисопролол моно, 2,5 мг). Показание: **только ХСН** (узкая регистрация — низкая доза специально для титрации в ХСН).
- `konkor-nst/` — **Конкор НСТ** (бисопролол + гидрохлортиазид 6,25 мг, 3 дозировки: 2,5+6,25, 5+6,25, 10+6,25). Показание: АГ.

## Конвенция именования

`YYYY-MM-DD_препарат_тип-документа.{pdf,md}`, где:
- `YYYY-MM-DD` — дата документа (редакции / экспертного отчёта), не дата загрузки.
- `препарат` — `konkor`, `konkor-am`, `konkor-kor`, `konkor-nst`.
- `тип-документа` — `smpc` (ОХЛП), `pil` (инструкция для пациента), `expert-report`, и т. п.

Например: `konkor-am/2025-11-28_konkor-am_smpc.pdf`.

## Принципы работы

1. **Источник истины по регистрационным показаниям и дозам** — только ОХЛП в этой папке. Не из памяти модели, не из вторичных источников.
2. **Off-label маркировка обязательна** — если задача касается препарата вне зарегистрированных показаний (например, Конкор АМ у популяции АГ + ИБС), материал помечается явно (см. `INSTRUCTIONS.md` Блок 5 и правило «дисклеймер „получены у“» в `decisions/2026-05-18_slide-building-principles.md`).
3. **Версионность.** Старые редакции ОХЛП не удаляются. При появлении новой редакции старая остаётся рядом, чтобы видеть, что менялось.
4. **MD-конспекты — опционально, по запросу.** Если для частых задач нужен быстрый доступ к показаниям / дозам / ключевым НЯ — рядом с PDF можно положить MD-конспект с тем же базовым именем. Это даёт greppable текст без открытия PDF при каждом обращении.
