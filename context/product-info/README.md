# context/product-info

Регистрационные документы по препаратам Конкор: инструкции по применению РФ, ОХЛП (SmPC), локальные брендовые сообщения, утверждённые сравнения.

**Подпапки рекомендуется создавать по препарату:**
- `konkor/` — бисопролол (моно)
- `konkor-am/` — бисопролол + амлодипин
- `konkor-nst/` — бисопролол + гидрохлортиазид 6.25 мг

**Важно:** все материалы для внешней аудитории должны соответствовать зарегистрированной инструкции (Блок 5.1 INSTRUCTIONS.md). Использование вне инструкции маркировать как off-label.
