## Что в карточках key-points

Каждая карточка извлекает из ОХЛП только данные для **regulatory compliance check** и работы с материалами:
- **Раздел 4.1 Показания — дословно** (для off-label маркировки).
- **4.2 Дозирование** — старт, титрация, максимум, особые группы.
- **4.3 Противопоказания** — все, структурированно.
- **4.4 Особые указания** — только клинически релевантное (коморбидные пациенты, прекращение терапии, специфические предупреждения).
- **4.5 Взаимодействия** — приоритетные (нерекомендуемые и значимые с осторожностью).
- **4.6, 4.7, 4.8, 4.9** — компактно, акцент на практически важное.
- **Типовые применения и off-label ситуации** — с правильной формулой дисклеймера.

**Намеренно НЕ включено:** производственные данные, держатели РУ, адреса регуляторов, упаковка, фармацевтические свойства (раздел 6), полная фармакология (раздел 5) — для compliance это не нужно, при необходимости открывается полный PDF.

## Заметки по портфелю

- **Конкор АМ зарегистрирован только при АГ.** Использование данных у популяции АГ + ИБС (исследования Чесниковой 2014, Скибицкого 2015) требует дисклеймера «получены у пациентов с АГ и сопутствующей ИБС», не «применимы для пациентов с АГ и ИБС» — см. деку Конкор АМ v2.0 и `decisions/2026-05-18_slide-building-principles.md`.
- **Конкор vs Конкор Кор** — это **разные** регистрации. Конкор Кор (2,5 мг) — единственная зарегистрированная форма бисопролола с дозой <5 мг, специально создана для **титрации в ХСН** (старт с 1,25 мг = ½ таблетки). У препарата Конкор (5/10 мг) показания шире, но дозы выше — для титрации ХСН он не оптимален. При материалах по ХСН учитывать эту разницу.
- **Конкор НСТ имеет три дозировки бисопролола** (2,5 / 5 / 10 мг) при фиксированной дозе гидрохлортиазида 6,25 мг. Это позволяет ступенчатую титрацию β-блокатора в комбинации. В разделе 4.2 ОХЛП явно описана только титрация 2,5+6,25 → 5+6,25; дозировка 10+6,25 зарегистрирована и доступна, но в 4.2 без явных шагов титрации.
- **Конкор НСТ — беременность и лактация — АБСОЛЮТНОЕ противопоказание** (в отличие от Конкор моно / Конкор АМ, где «не рекомендуется» с оговорками).

## Открытые задачи

- Инструкции для пациента (PIL) — не загружены.
- Локальные брендовые сообщения / утверждённые сравнения — не загружены.
- При появлении новых редакций ОХЛП — добавлять рядом (старые не удалять), обновлять таблицу и при необходимости карточки.
