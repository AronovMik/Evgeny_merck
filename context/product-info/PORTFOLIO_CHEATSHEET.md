# Портфель Конкор® — кросс-препаратный cheat-sheet

> Сводная справка для **быстрого «вертикального» сравнения** препаратов портфеля. Когда вопрос «какой из четырёх подходит под кейс / на что обратить внимание» — смотреть сюда первым. Детали по каждому препарату — в карточках key-points.

## Подбор препарата по клиническому сценарию

| Кейс | Что подходит | Что НЕ подходит / off-label | Регуляторная заметка |
|---|---|---|---|
| **Изолированная АГ (мягкая/умеренная)** | Конкор НСТ; Конкор моно; Конкор АМ (если уже подобраны бисоп + амло раздельно) | Конкор Кор (вне показаний) | — |
| **Тяжёлая АГ** | Конкор (выше 10 мг возможно), Конкор АМ (выше 10+10 — нет) | Конкор НСТ (off-label — показание ограничено мягкой/умеренной АГ) | Для НСТ — off-label маркировка |
| **АГ + стабильная стенокардия** | **Конкор моно** (в инструкции) | Конкор АМ при стенокардии — **off-label**; Конкор НСТ при стенокардии — **off-label** | Для Конкор АМ слайды с исследованиями Чесниковой/Скибицкого требуют дисклеймера «получены у» |
| **АГ + ИБС (включая ХКС без выраженной стенокардии)** | Конкор моно (в инструкции у двух из трёх показаний); | Конкор НСТ — с осторожностью (выраженный атеросклероз коронарных артерий — особое указание) | — |
| **ХСН — стартовая титрация (1,25 мг)** | **Конкор Кор** (единственная форма с делением до 1,25 мг) | Конкор 5/10 мг — нет риски для деления на ¼ | Связка Конкор Кор → Конкор при достижении 5 мг |
| **ХСН — поддержка (после титрации)** | Конкор Кор; Конкор 5/10 мг | Конкор АМ при ХСН — с осторожностью (амлодипин у ХСН III–IV ФК NYHA неишемического генеза — риск отёка лёгких); Конкор НСТ при декомпенсации — противопоказан | — |
| **АГ + СД** | Конкор моно; Конкор АМ | Конкор НСТ — с осторожностью (тиазид влияет на гликемию; + бисопролол маскирует гипогликемию) | Контроль гликемии при СД на любом β-блокаторе |
| **АГ + подагра / гиперурикемия** | Конкор моно; Конкор АМ | Конкор НСТ — с осторожностью (тиазид ↑ мочевую кислоту) | — |
| **АГ + ХОБЛ или нетяжёлая БА** | Все 4 с осторожностью; обязательно бронходилататоры; старт с минимальной дозы | Все 4 противопоказаны при **тяжёлой БА** | Свежая поддержка по бисопрололу при ХОБЛ — **PACE 2026** (см. деку Конкор АМ v2.0, блок 13) |
| **АГ + ХПН** | Конкор моно / Конкор АМ (до 10 мг бисоп) при КК <20; | Конкор НСТ **противопоказан** при КК ≤30 мл/мин | — |
| **АГ + тяжёлая печёночная недостаточность** | Конкор моно / Конкор АМ (до 10 мг) | Конкор НСТ — **противопоказан** | — |
| **АГ + беременность** | По жизненным показаниям бисопролол моно/АМ — только если польза > риск (β1-селективный — предпочтительнее неселективных) | Конкор НСТ — **АБСОЛЮТНО противопоказан** | — |
| **АГ + лактация** | Все не рекомендуются | Конкор НСТ — **противопоказан** (плюс ГХТЗ **подавляет лактацию**) | — |
| **Гипертонический криз** | Никакой из портфеля (не для криза) | Конкор НСТ явно: «не применять для купирования гипертонического криза» | — |
| **Острый ИМ** | Хроническая поддержка — Конкор моно / Конкор АМ (с осторожностью); | Конкор НСТ при ОИМ — **не рекомендуется** (недостаточно опыта); Конкор моно при ХСН + ИМ <3 мес — недостаточно данных | — |
| **Феохромоцитома** | Все 4 — только на фоне α-блокаторов | Без α-блокаторов — все **противопоказаны** | — |
| **Стенокардия Принцметала / вазоспастическая** | Все 4 — с осторожностью (бисопролол β1-селективен, но коронароспазм не исключён) | Не противопоказаны, но риск приступа | — |
| **Псориаз** | Все 4 с осторожностью | — | β-блокаторы могут обострять; тиазид (Конкор НСТ) дополнительно даёт фоточувствительность |
| **АГ + риск удлинения QT (или препараты, удлиняющие QT)** | Конкор моно / Конкор АМ предпочтительнее | Конкор НСТ — особо с осторожностью (гипокалиемия от ГХТЗ + QT-удлиняющие препараты → «пируэт») | Контроль ЭКГ и K⁺ если Конкор НСТ обязателен |
| **АГ + сердечные гликозиды (дигоксин)** | Конкор моно / Конкор АМ | Конкор НСТ — с осторожностью (гипокалиемия ↑ токсичность гликозидов) | — |
| **Спортсмен / допинг-тесты** | Прозрачно сообщить о составе | Конкор НСТ — явно отмечено в ОХЛП: возможен положительный допинг-тест | — |

## Off-label типовые ситуации — какой дисклеймер использовать

| Ситуация | Препарат | Линия маркировки |
|---|---|---|
| Конкор АМ при АГ + ИБС / АГ + стенокардии | Конкор АМ | «Конкор® АМ зарегистрирован для лечения АГ. Данные получены у пациентов с АГ и сопутствующей ИБС.» |
| Конкор АМ при АГ + ХСН | Конкор АМ | Не позиционировать; для ХСН — Конкор / Конкор Кор |
| Конкор АМ как старт АГ «с нуля» | Конкор АМ | Корректно: «при недостаточном контроле на монотерапии — перевод на FDC в тех же дозах»; не: «начать с Конкор АМ» |
| Конкор НСТ при тяжёлой АГ | Конкор НСТ | Off-label; обычно не позиционировать |
| Конкор Кор при АГ или стенокардии | Конкор Кор | Off-label; направлять на Конкор |

См. также формулу «получены у» vs «применимы для» — `decisions/2026-05-18_slide-building-principles.md`, правило 4.

## Что специфично для каждого препарата (одной строкой)

- **Конкор** — широкие показания (АГ + стенокардия + ХСН); в АГ можно до 20 мг.
- **Конкор АМ** — только АГ как **замещение** свободной комбинации; FDC бисоп + амло.
- **Конкор Кор** — только ХСН; **низкая доза 2,5 мг** для старта титрации 1,25 мг.
- **Конкор НСТ** — только мягкая/умеренная АГ; **много тиазид-специфичных рисков** (электролиты, QT, гликемия, мочевая кислота, НМРК); беременность/лактация — абсолютное противопоказание.
