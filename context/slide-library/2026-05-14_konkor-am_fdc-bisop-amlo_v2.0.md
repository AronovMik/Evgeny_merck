## Назначение в библиотеке

1. **Источник готовых слайдов** для будущих презентаций по Конкор® АМ и смежной тематике (FDC, переход с моно/свободных комбинаций, безопасность бисопролола в коморбидных популяциях).
2. **Образец методологии** построения слайдсета (см. [decision: принципы построения деки](../../decisions/2026-05-18_slide-building-principles.md)) — переносится на следующие деки по другим препаратам.
3. **Брифовый материал** для подготовки медсоветников и для ответов на вопросы экспертов.

## Регуляторные правила, обязательные при переиспользовании

### Дисклеймер «получены у» (off-label популяция)

Конкор® АМ зарегистрирован для **лечения АГ**. Когда используются слайды с данными у популяции **АГ + ИБС** (блок 9: Чесникова 2014, Скибицкий 2015; слайд 38 блока 6) — **обязателен дисклеймер**:

✅ **Используем:**
> «Конкор® АМ зарегистрирован для лечения АГ. Данные получены у пациентов с АГ и сопутствующей ИБС.»

❌ **НЕ используем (off-label promotion риск):**
> «Данные применимы для пациентов с АГ и ИБС.»

**Открытая задача:** формулировка не согласована с юристами/комплаенс Merck — перед использованием в реальной коммуникации обязательное юридическое согласование.

### Удалённые материалы — не возвращать без нового обоснования

- **Слайд про вспомогательные вещества в дженериках** — ФЗ «О рекламе» ст. 24 (сравнительная реклама ЛС) + методологические дыры. Возвращать **только** при наличии исследований биоэквивалентности конкретных дженериков бисопролола с клинически значимыми различиями.
- **Слайд про «технологию производства Merck»** — без доказательной поддержки (биодоступность, стабильность) не возвращать.
- **Hostalek 2015 (три слайда)** — дублируют Hostalek 2014 / Czarnecka, удалены сознательно.

## Рамка гайдлайнов

Дек построен в первую очередь на:
- **ESC 2024** — Chronic Coronary Syndromes (концепт ХКС, Diamond Approach, рекомендация β-блокатор + ДГП-БКК).
- **ESC 2024** — Elevated Blood Pressure and Hypertension (поддержка FDC).
- **КР МЗ РФ 2024** — Артериальная гипертензия (явно называет β-блокатор + ДГП-БКК как стратегию выбора при сочетании АГ + ИБС).
- **КР МЗ РФ 2024** — Стабильная ИБС (контекст ОМТ).

Все четыре документа — в `context/guidelines/`. Расхождения между КР МЗ РФ и ESC по сочетанию АГ + ИБС в этой версии деки **не маркировались отдельно** — для будущих ревизий уточнить у Евгения, нужно ли их подсветить (Правило 5 в `CLAUDE.md`).

## Терминология (для согласованности с этой декой)

| Англицизм | Замена |
|---|---|
| HR (hazard ratio) | ОР (отношение рисков) |
| OR (odds ratio) | ОШ (отношение шансов) |
| RR | ОР (относительный риск) |
| 95% CI | 95% ДИ |
| mmHg | мм рт. ст. |

**FDC оставлено** + расшифровка: «ФК» в кардиологии может означать «функциональный класс» (например, ФК II–III СН) — путаница недопустима.

**Win ratio** (PACE 2026) — обязательная сноска: «статистический метод сравнения групп по иерархии исходов; значение 1,0 = нет различий между группами».

**Открытая задача:** унификация форм «β-блокатор / ББ / БАБ / бета-блокатор / β-адреноблокатор» (рекомендация Евгения — «β-блокатор» + «ББ») и «БКК / АК / ДГП-БКК / ДГП-АК» (рекомендация — «БКК» + «ДГП-БКК»). Не критично, но желательно в следующей ревизии.
