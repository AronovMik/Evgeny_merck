# Slide Library — переиспользуемые слайды

Каталог готовых презентаций и слайдов, которые можно использовать как референс или конструктор при подготовке новых материалов.

## Назначение

- **Источник слайдов:** при появлении новой задачи Claude должен проверить, нет ли в библиотеке готового слайда / блока, который можно переиспользовать или взять за образец.
- **Версионность:** в имени файла фиксируется версия и дата последней правки. Старые версии не удаляются — лежат рядом, чтобы видеть эволюцию материала.
- **Не путать с `tasks/slides/`:** там лежат слайды по конкретным разовым задачам в работе. Сюда — только то, что Евгений хочет иметь под рукой как библиотеку.

## Конвенция именования

`YYYY-MM-DD_препарат_тема_vX.Y.{pptx,md}`

Где:
- `YYYY-MM-DD` — дата последней правки версии (а не загрузки в репозиторий).
- `препарат` — `konkor`, `konkor-am`, `konkor-nst`, либо `class` если о классе β-блокаторов.
- `тема` — короткий тег без пробелов: `stable-angina-htn-fdc-transition`, `hf-mortality`, `dose-titration` и т. п.
- `vX.Y` — версия деки по нумерации Евгения.

Для каждой деки рядом с PPTX лежит MD-карточка с тем же именем: краткое описание, оглавление по разделам, перечень переиспользуемых слайдов с тегами, источники, история версий.

## Как пользоваться

1. Перед началом задачи на слайды/презентацию — открыть `INDEX.md`, найти релевантные деки.
2. Открыть MD-карточку нужной деки — посмотреть, какие конкретно слайды могут пригодиться.
3. Только после этого открывать сам `.pptx` (он тяжёлый — 10+ МБ, не подгружать без необходимости).

## Файлы

- `INDEX.md` — сводный каталог всех дек в библиотеке.
- `<имя_деки>.pptx` — сам файл презентации.
- `<имя_деки>.md` — карточка деки (описание, оглавление, переиспользуемые блоки, источники, история).
