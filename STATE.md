## Последние ключевые решения

- **Памятка онбординга переехала из базы знаний в поле Description агента.** В базе она печаталась одним блоком вместе с первым кейсом — то есть когда читать её уже поздно, кейс перед глазами. Лимит поля — 500 знаков (установлен опытным путём). `simulator/onboarding.md` остаётся версионируемым исходником текста и **в базу знаний не загружается**.
- **Версии промта не правятся задним числом.** v19 менялся на месте четыре раза, и стало неясно, какая версия загружена в агент. Начиная с v20 каждое содержательное изменение — новый файл `medrep_prompt_vNN.md`.
- **Дословные корпоративные цитаты не редактируются — поправка ставится рядом, в том же чанке.** Применено к CIBIS-II ↓32% в `competitive_messaging`: цитата слайда сохранена как точная запись PPTX, поправка по первоисточнику (↓34%, Lancet 1999) стоит следующим абзацем. Это же правило — общий приём против дефектов извлечения: речевое утверждение и его ограничение обязаны попадать в один извлекаемый фрагмент, иначе агент выдаёт утверждение без границы.
