Вердикт председателя

Где совет соглашается. v5 существенно сильнее предыдущих версий — пословные клинические ошибки убраны, диагнозы переписаны по образцам КР МЗ РФ, USP усилен данными Verma 2018. Switch-логика безупречна по инструкции Конкор АМ.
Где совет расходится. Голос распределился: A (принять) / B (с правками) / C (не принимать). Peer review: 2/3 reviewers выделили B как самый сильный ответ; 1/3 — C; 3/3 — A как имеющий самое большое слепое пятно («резолюция без анализа»).
Слепые пятна, поймал peer review.
  • Универсально (все 3 reviewers): narrative Шага 3 («зачем переключать стабильного пациента?») — первый вопрос кардиолога-аудитории; прямого ответа в тексте кейса нет.
  • Reviewer 2: целевой уровень АД с обоснованием по КР МЗ РФ (с учётом ХБП А2 + ИБС) явно не сформулирован.
  • Никто не подсветил, что switch с двух монокомпонентов в тех же дозах — единственный валидный путь применения Конкор АМ по инструкции, и это сам по себе сильный позиционный аргумент.
Рекомендация. v5 НЕ принять без 3 правок:
  1. apply СМАД-формулировка — убрать видимое противоречие. Явная связка: «Нормальное ночное снижение (диппер). При этом ночное АД 132/78 ≥120/70 — ночная гипертензия по КР МЗ РФ АГ-2024 (характер снижения и абсолютный уровень — независимые параметры суточного профиля)».
  2. apply Шаг 1–2 — атрибуция «по решению лечащего врача» к титрации бисопролола.
  3. apply Шаг 3 — явный нарратив: «Пациент стабилизирован на свободной комбинации в течение 4 нед. По инструкции Конкор АМ показанием является switch с эквивалентных доз монокомпонентов. Цель перевода — повышение приверженности и FDC-ассоциированное снижение твёрдых конечных точек (Verma 2018)».
Не применяем.
  • skip Находка 4 (ХБП А2 без повторности) — пользователь явно попросил убрать «повторно через 3 мес», осознанный компромисс.
  • discuss Точечная правка по ХОБЛ-формулировке (мягче, со ссылкой на инструкцию) — обсудим отдельно.
Сделать первым. Добавить нарратив Шага 3 — снимает универсальное возражение аудитории «зачем менять схему стабильному пациенту?» одним блоком текста.

Ответы участников

Кардиолог 1 (за) — ПРИНЯТЬ безоговорочно
Кейс v5 клинически валиден и готов к использованию. Стратегическое обоснование: единственный валидный сценарий применения Конкор АМ по инструкции — switch с двух монокомпонентов в тех же дозах после стабилизации. Логика Шаг 1 → 2 → 3 безупречна. Архетип узнаваем. Построчная проверка — что особенно сильное: - Стресс-ЭхоКГ как метод верификации ишемии — корректно: гипокинез сегментов передней и переднеперегородочной стенок при ЧСС 130 соответствует зоне стеноза ПНА 70%. - Характер ритма — только по ЭКГ: «синусовый ритм» в ЭКГ покоя; пульс описан как «ритмичный, удовлетворительного наполнения» — без атрибуции характера. Принцип №7 соблюдён. - Диагноз ХОБЛ верифицирован постбронходилатационной спирометрией. - ХБП С2 А2 — стадирование верное по обоим критериям. - ИММЛЖ 124 г/м² — превышение порога ГЛЖ для мужчин (≥115). - Диагноз АГ: «ГБ III стадии. Целевой уровень АД не достигнут. Риск 4» — без степени, по образцу КР МЗ РФ. - Switch на Конкор АМ — дозы идентичны (бисо 10 + амло 5 = Конкор АМ 10/5). - Кашель типичен для ХОБЛ, не для иАПФ. Итог: кейс прошёл построчную проверку без клинических ошибок. Принимаем без доработки.
Кардиолог 2 (против) — НЕ ПРИНИМАТЬ
Два принципиальных дефекта. Построчные находки: 1. СМАД — «нормальное ночное снижение; ночная гипертензия» — логическое противоречие в одной строке без связки. Редакционная небрежность. 2. ХОБЛ — корректно верифицирован. 3. ИМТ 27,14 → 27,1 — допустимая погрешность. 4. ХБП С2А2 — единственное измерение альбуминурии без подтверждения повторно через ≥3 мес — формально не верифицирует А2 по КР МЗ РФ. 5. На Шаге 2 уже полный контроль (АД 125/77, ЧСС 62, приступов нет) — зачем Шаг 3? Переключение на FDC при достигнутой цели — слабый нарратив. Аудитория спросит: «вы меняете схему у стабильного пациента ради удобства упаковки?» Стратегические возражения: Verma 2018 — ретроспективная когорта, бисо+амло не выделены отдельно. Использование как прямого доказательства для Конкор АМ методологически уязвимо. Итог: до устранения СМАД-противоречия и неверифицированной ХБП А2 — не выносить.
Маркетолог Merck — ПРИНЯТЬ с 2 правками
Регуляторно-маркетинговые находки: - Шаг 1–2: «Конкор увеличен с 5 до 10 мг по динамике ЧСС» — прямая инструкция по титрации; медпред не имеет права воспроизводить как самостоятельную рекомендацию. Нужна атрибуция: «решение лечащего врача». - USP «Единственная в РФ FDC бисо+амло» — регуляторно чистое; требует верификации актуальности реестра ГРЛС. - USP «Допустим при ХОБЛ GOLD 1» — потенциальный off-label риск: ХОБЛ в инструкции — «с осторожностью» без градации по GOLD. Нужна ремарка «по решению врача при лёгкой обструкции, с мониторингом» + ссылка на инструкцию. - Verma 2018: популяция АГ без обязательной ИБС/ХОБЛ; экстраполяция формально не валидирована. USP-блок v5 значительно усилен. Три кита работают: уникальность FDC, упрощение схемы (2 vs 3), численные значения Verma. Для российского кардиолога эмоционально убедителен. Итог: принять с двумя правками — атрибуция титрации, смягчение ХОБЛ-допустимости со ссылкой на инструкцию.

Противоречие в СМАД, повторность альбуминурии и вопрос об оправданности Шага 3 — реальные возражения, которые задаст кардиолог-аудитория. 2. Самое большое слепое пятно — A. «Кейс прошёл проверку без ошибок» — резолюция без анализа. 3. Упустили все.
