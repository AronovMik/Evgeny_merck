# Критерии качества клинических кейсов — на основе типологии

## 1. ТРИ КАТЕГОРИИ КЕЙСОВ

### Категория 1 — Целевой кейс
Пациент клинически подходит для одного из продуктов линейки Конкор. Есть показание по инструкции, резерв по АД/ЧСС, ясное продуктовое решение из типологии (А1–А4, Б1–Б4, В1–В3). Возражение врача отрабатывается по структуре Признание → Переключение → Аргумент.

### Категория 2 — Нецелевой кейс
Пациент не подходит. Эталонный ответ — отказ от продавливания + переключение на другого пациента. Соответствует Типу Г из типологии.

### Категория 3 — Пограничный кейс
Формально продукт натянуть можно, но путь наименьшего сопротивления — мягкий выход. Эталон учит оценивать соотношение усилие/результат.

**Распределение для генератора:** целевые 60% / пограничные 25% / нецелевые 15%.

---

## 2. КРИТЕРИИ НЕЦЕЛЕВОГО КЕЙСА

Кейс относится к Категории 2, если выполняется одно или несколько условий:

### 2.1. Нет клинического показания для бисопролола по инструкции
- Нет ИБС (стенокардии)
- Нет АГ или АГ контролируется текущей терапией
- Нет ХСН
- Нет симпатикотонии с тахикардией (ЧСС <80 в покое)
- Нет пост-ИМ в анамнезе

### 2.2. Есть прямое противопоказание из инструкции Конкора
- Острая сердечная недостаточность / декомпенсированная ХСН
- AV-блокада II–III степени без кардиостимулятора
- Синдром слабости синусового узла
- Синоатриальная блокада
- Выраженная брадикардия (ЧСС <60 до начала терапии)
- Выраженная артериальная гипотензия (САД <100)
- Тяжёлая бронхиальная астма или тяжёлая ХОБЛ с обструкцией
- Тяжёлые нарушения периферического артериального кровообращения
- Феохромоцитома без одновременной α-блокады
- Метаболический ацидоз

### 2.3. Пациент уже на оптимальной терапии с адекватным контролем
- АД в целевых значениях по возрасту
- ЧСС 55–60 при ИБС или <75 при АГ
- Нет клинических симптомов (стенокардия, одышка)
- Терапия переносится хорошо, приверженность высокая
- Изменять терапию нет клинических оснований

### 2.4. Пациент «запечатан» в конкурентной экосистеме — Тип Г1
- На конкурентной FDC (Престанс, Эксфорж, Ко-Эксфорж, Нолипрел)
- ББ не показан ИЛИ уже стоит конкурентный ББ в оптимальной дозе
- Врач лоялен конкуренту, ранее переключение не обсуждалось

### 2.5. Ситуация вне компетенции медпреда
- Терминальная стадия другого заболевания (онкология, ХПН 5 ст. и т.д.)
- Пациент на стационарном лечении по острому состоянию
- Вопросы, требующие консилиума или узкой специализации

### 2.6. Ситуация требует обсуждения вне зарегистрированных показаний Конкора
**Показания Конкора по инструкции: АГ, ИБС (стенокардия), ХСН.** Медпред не может продвигать препарат вне этих показаний, даже если клинически бисопролол работал бы.

Нецелевые по этому критерию:
- **Изолированная ФП** без АГ, без ИБС, без ХСН — обсуждение контроля ЧСС выходит за инструкцию
- Контроль ЧСС при тиреотоксикозе, синусовой тахикардии неясной этиологии, IST
- Вторичные гипертензии без АГ-компонента (например, для контроля тремора при эссенциальном треморе)
- Любое показание, которого нет в инструкции Конкора, даже если в практике так лечат

**Важная тонкость по ФП:**
- ФП + АГ → целевой кейс (показание по АГ, контроль ЧСС — фармакологическое свойство)
- ФП + ИБС → целевой кейс (показание по ИБС)
- ФП + ХСН → целевой кейс (показание по ХСН)
- Изолированная ФП без АГ/ИБС/ХСН → нецелевой

### 2.7. Обсуждение требует доз или комбинаций вне инструкции
- Доза выше 10 мг/сут (инструкция ограничивает максимум 10 мг)
- Дозы Конкор АМ, Конкор НСТ вне зарегистрированных фиксированных дозировок
- Комбинации с противопоказанными препаратами (верапамил в/в, флоктафенин)

## 3. КРИТЕРИИ ПОГРАНИЧНОГО КЕЙСА

Формальное показание есть, но усилия несоразмерны результату:

### 3.1. Показание формальное, но клинически слабое
- ИБС в анамнезе, но стенокардии нет, ЧСС 68, АД в цели, стабилен на текущей терапии
- АГ 1 степени, АД 140/88 на монотерапии, никаких коморбидностей, пациент доволен

### 3.2. Врач категорически против, аргументов не слышит
- После одной попытки аргументации врач упирается в нерациональное возражение
- Дальнейшее продавливание = риск потери отношений

### 3.3. Пограничные возражения типа В8
- В8а: «ББ не улучшают прогноз при АГ без ИБС/ХСН» — у пациента действительно изолированная АГ без коморбидностей
- В8б: «Ивабрадин лучше» — у пациента непереносимость ББ в анамнезе
- В8в: ценовой вопрос, пациент не может себе позволить оригинал

## 4. КРИТЕРИИ КАЧЕСТВА ЦЕЛЕВОГО КЕЙСА

### 4.1. Клиническая реалистичность
- Возраст, пол, анамнез, сопутствующие заболевания — согласованы друг с другом
- АД и ЧСС на осмотре согласованы с терапией и состоянием
- Цифры в ЭКГ/лабораторных данных не противоречат клиническим
- Лабораторные данные включают только то, что релевантно (не перегружать)

### 4.2. Отсутствие «ловушек» — детали не уводят от темы
Запрещённые элементы:
- Эпизоды тахикардии или нерегулярного ритма на фоне стресса → вопрос про ФП/АВУРТ
- Изолированные суправентрикулярные экстрасистолы → вопрос про холтер
- Неполный набор обследований (отсутствие ТТГ при тахикардии, отсутствие СМАД при пограничной АГ)
- Несоответствие ЧСС на осмотре и на ЭКГ без объяснения
- Зоны гипокинезии в ЭхоКГ, не соответствующие зонам изменений на ЭКГ
- Упоминание патологий, требующих дифференциального диагноза (тиреотоксикоз, феохромоцитома)

### 4.3. Соответствие инструкциям и клинрекам
- Показания, дозы и комбинации — только в рамках зарегистрированных показаний
- Конкор АМ — только switch-терапия после подбора на раздельных компонентах; Конкор НСТ — стартовая комбинация (2,5+6,25 → 5+6,25 по ОХЛП). Если пациент уже получал 5 мг в кейсе, можно сразу 5+6,25
- Сопутствующая терапия соответствует клинрекам (статин при ИБС, антиагрегант при пост-ИМ, и т.д.)
- Целевые значения АД и ЧСС — по действующим рекомендациям (ESC CCS 2024, ESH 2023, КР МЗ РФ)

### 4.4. Валидность комбинации по матрице типологии
Продуктовое решение × возражение × профиль врача — должны быть в списке валидных комбинаций. Исключать невалидные:
- В3 (против FDC) + А1–А4 (Конкор моно) — конфликта нет, возражение бессмысленно
- В5 (другой ББ) + Б1–Б3 (Конкор АМ) — вопрос не про FDC
- В6 (дженерик) + Б1–Б3 — пациент не на бисопрололе
- Конкор НСТ + подагра / непереносимость тиазидов
- Конкор АМ + отёки на АК в анамнезе

### 4.5. Возражение врача клинически оправдано
- Имеет рациональное зерно (иначе Признание невозможно)
- Реально встречается в практике
- Не выходит за рамки своей категории из типологии (В1–В9)

### 4.6. Возражение соответствует профилю врача
- Терапевт-осторожный: В1, В2, В4 — боится титрации, страх побочек
- Терапевт-нигилист: В7 — «это потолок»
- Кардиолог-рационализатор: В1, В3, В6 — логика неполная
- Кардиолог с конкурентным предпочтением: В5
- Кардиолог, избегающий ББ: В4
- Гайдлайн-пурист: В8а — требует РКИ
- Полипрагмазист: В3 (наоборот — за FDC)
- Скептик по оригиналам: В8в
- Лояльный конкуренту: В5, В9

### 4.7. Есть резерв для продуктового решения
Цифры должны позволять сделать предлагаемое действие:
- Для А2 (титрация до 10 мг): АД >135/85, ЧСС >65
- Для Б1 (Конкор → Конкор АМ) — два допустимых сценария: (1) ЧСС в цели (<65), АД выше цели (>140/90) — классический переход; (2) ЧСС НЕ в цели, но есть гемодинамический резерв и клиническая логика добавления амлодипина (контроль АД + антиангинальный эффект), особенно когда врач не готов к ап-титрации ББ. Во втором сценарии целевая ЧСС — контекст/следующий шаг (бисопролол), не блокер для добавления амлодипина
- Для В3/НСТ-3: ЧСС в цели, АД выше цели, непереносимость АК в анамнезе
- Для А4 (замена ББ): ЧСС не в цели И/ИЛИ клинический аргумент против текущего ББ

### 4.8. Есть однозначное продуктовое решение или ясная развилка
- Либо одно продуктовое решение (и оно очевидно из типологии)
- Либо две чёткие альтернативы (например, К-01: А2 титрация ИЛИ Б1 Конкор АМ 5+5) — с ясным объяснением, когда какой путь
- Развилка «титрация ББ vs добавление амлодипина» допускается и поощряется ТОЛЬКО с явным правилом «когда какой путь» (зависит от профиля врача и гемодинамического резерва). Выбор пути может предложить и сам врач. Голое «либо–либо» без правила выбора — недостаток эталона/ответа медпреда

## 5. КРИТЕРИИ КАЧЕСТВА ЭТАЛОННОГО ОТВЕТА

### 5.1. Для целевого кейса — структура Признание → Переключение → Аргумент

**Признание:**
- Конкретное указание, что в позиции врача рационально
- Не формальное «понимаю вас»
- Упоминает реальный рациональный элемент (клинрек, логика, опыт)
- 1–2 предложения

**Переключение:**
- Опирается на данные — клинреки, исследования, фармакология
- НЕ «бренд лучше», НЕ «эмоциональные аргументы»
- Указывает на фактор, который врач упустил или недооценил
- Использует сквозные аргументы из типологии (раздел 6): целевая ЧСС, 88% достигают 10 мг, CIBIS-II, приверженность FDC, селективность, датское исследование ЭД и т.д.
- 2–4 предложения

**Аргумент:**
- Конкретное продуктовое решение: препарат, доза, форма выпуска
- Обоснование, почему именно эта комбинация закрывает кейс
- Опирается на характеристики пациента из кейса (цифры АД, ЧСС, резерв, коморбидности)
- При необходимости — следующий шаг в схеме лечения
- 2–4 предложения

### 5.2. Для нецелевого кейса — структура Признание → Переключение

**Признание:**
- «Этот пациент сейчас не целевой для нашего продукта»
- Конкретное клиническое обоснование почему (противопоказание, отсутствие показания, оптимальный контроль на конкуренте с собственной доказательной базой)
- Не извиняется, не оправдывается

**Переключение:**
- Конкретный запрос к врачу: «Есть ли у вас пациенты с [конкретный профиль, соответствующий продукту]?»
- Профиль сформулирован предметно, не абстрактно
- Сохраняет позитивный контекст визита

### 5.3. Для пограничного кейса — Признание + оценка + переключение

**Признание:**
- Подтверждение **наличия клинической зацепки** (минимум одна работающая опора аргументации) + указание на **конкретный реалистичный фактор**, делающий путь непродуктивным:
  - Категоричность врача в защите текущей терапии
  - Ценовой барьер у пациента
  - Стабильная компенсация при наличии теоретической зацепки
  - Неоптимальный момент визита (перегруженный приём, экстренная ситуация в смежной нозологии)

**ВАЖНО — НЕ путать с нецелевым:**

В формулировке Признания **не используй фразу «слабое клиническое обоснование»** — она создаёт двусмысленность с нецелевым кейсом. Пограничный — это «зацепка есть, но дожимать не выгодно». Нецелевой — это «зацепки нет вообще».

**Переключение:**
- Запрос на других пациентов
- **Явная возможность вернуться** к этому пациенту позже при изменении обстоятельств (в отличие от нецелевого, где такой возможности обычно нет — пациент стабилен или препарат вне показаний)

### 5.3.1. Различительный критерий пограничный vs нецелевой (КРИТИЧЕСКИ ВАЖНО)

Чтобы агент при генерации правильно классифицировал кейс, используй чёткий критерий:

**Пограничный** — есть **минимум одна реалистичная клиническая зацепка** для аргументации в пользу Конкора (например, коморбидность ХОБЛ при возражении про карведилол; задокументированная плохая приверженность при возражении про двукратный приём; недавний инфаркт; возрастной риск). Плюс **есть внешний фактор**, делающий выгоднее не дожимать.

**Нецелевой** — **клинической зацепки нет в принципе**. Пациент стабилизирован на конкуренте с собственной доказательной базой и нет коморбидности/индикаторов, дающих Конкору преимущество; противопоказание; вне показаний; экосистема конкурента полная и обоснованная.

**Типичная ошибка**: стабильный пациент на карведилоле/метопрололе/небивололе **без коморбидности ХОБЛ, без post-MI, без индикаторов плохой приверженности** — это **нецелевой**, а не пограничный. Если для Конкора нет ни одной работающей опоры аргументации, кейс автоматически нецелевой.

### 5.4. Общие требования ко всем эталонам

- **Не выходит за рамки инструкции** — только зарегистрированные показания и дозы
- **Не содержит медицинских советов от медпреда** — не «увеличьте дозу до 10 мг», а «по клинрекам целевая ЧСС 55–60, следующий шаг в титрации — 10 мг, АД позволяет»
- **Не off-label** — если аргумент требует off-label применения, продуктовое решение должно меняться
- **Комплаентно для фармкомпании** — формулировки, приемлемые с точки зрения регуляторики
- **Использует язык типологии** — сквозные аргументы из раздела 6, не изобретает новые на ходу
- **Линейка доз Конкор АМ — обязательна** в целевых АМ-кейсах: указать все 4 дозировки (5/5, 5/10, 10/5, 10/10) как гибкость подбора, с привязкой «под уже подобранные дозы компонентов» (switch-only). Не подавать конкретную дозу как стартовую у наивного пациента
- **Адресует ВСЕ клинически значимые проблемы портрета** — если и ЧСС, и АД вне цели, проговорить разделение рычагов: ЧСС контролирует бисопролол, АД — оба компонента (амлодипин — по АД, не по ЧСС). ЧСС не оставлять «повисшей» при амлодипин-пути
- **Мост до Конкор АМ обязателен** в уместном (целевом по АМ) кейсе — независимо от того, какой путь ближе врачу

## 6. ПРОВЕРОЧНЫЙ ЧЕКЛИСТ ПЕРЕД ВЫДАЧЕЙ КЕЙСА

Генератор должен мысленно пройти чеклист перед выдачей:

**Для кейса:**
1. Категория определена (целевой / пограничный / нецелевой)?
2. Все клинические цифры внутренне согласованы?
3. Нет «ловушек», уводящих от темы?
4. Терапия и сопутствующая патология соответствуют инструкциям и клинрекам?
5. Комбинация из матрицы валидна?
6. Возражение соответствует профилю врача?
7. Есть резерв для продуктового решения (для целевых)?
8. Продуктовое решение однозначно или развилка ясна?

**Для эталона:**
1. Структура соответствует категории кейса?
2. Признание опирается на конкретный рациональный элемент позиции врача?
3. Переключение использует сквозные аргументы из типологии?
4. Аргумент — конкретное продуктовое решение с обоснованием?
5. Нет off-label, нет медицинских советов от медпреда?
6. Формулировки комплаентны?

Если хоть один пункт «нет» — переделать.

## 7. ЧТО ВАЖНО ДЛЯ УЧЕБНОЙ ЦЕННОСТИ

### Целевые кейсы учат
Строить аргументацию по структуре. Использовать конкретные данные клинреков и исследований. Находить резерв в цифрах пациента. Выбирать правильный продукт из линейки.

### Нецелевые кейсы учат
Распознавать бесперспективность. Не тратить время на продавливание. Сохранять отношения с врачом через честный выход. Формулировать запрос на других пациентов.

### Пограничные кейсы учат
Оценивать соотношение усилие/результат. Различать формальное показание и реальную клиническую потребность. Выходить из разговора, когда аргументация упирается в стену, сохраняя возможность вернуться.

### Главный риск, который нужно балансировать
Слишком легко обучившись «уходить», медпред превратит это в отмазку от работы. Поэтому:
- 60% кейсов — целевые (медпред побеждает через аргументацию)
- 15% нецелевые (проверка на умение честно выйти)
