# Тренажёр клинических случаев — Типология v2.0

## О документе

Этот документ — структурная основа для генерации клинических кейсов для тренировки медицинских представителей Мерк по линейке Конкор. Используется совместно с:
- **quality_criteria.md** — критерии качества кейсов и эталонов
- **mandatory_args.md** — ядро эталона по ситуациям; **arguments_table.md** — валидированные аргументы с цифрами и границами; **patient_portraits.md** — портреты пациентов; **competitive_messaging.md** — сравнения с конкурентами
- **Системный промт** — не файл базы знаний: лежит в поле Instructions агента
- **Инструкции к препаратам** — Конкор, Конкор АМ, Конкор НСТ; **в базу знаний не загружены**, их выдержки приведены внутри `arguments_table.md` с атрибуцией. Показание, дозу или противопоказание, которых там нет, не реконструировать по памяти

**При конфликтах приоритет:** инструкции к препаратам → quality_criteria.md → эта типология.

**Что изменилось относительно v1.0:**
- Введены три категории кейсов (целевой / пограничный / нецелевой) с распределением
- Тип Г (нецелевой) расширен с 2 до 7 подтипов
- Возражение В9 удалено (не возражение, а признак нецелевого кейса)
- Добавлено возражение В10 (ценовое)
- Изолированная ФП убрана из целевых кейсов (вне показаний Конкора)
- Структура эталонного ответа расширена на три категории
- Блок «защитных» кейсов переформулирован как подтип целевых (кейсы удержания)

## 1. ПРОДУКТОВЫЙ ПОРТФЕЛЬ

| Продукт | Состав | Дозировки | Зарегистрированные показания |
|---------|--------|-----------|-------------------------------|
| **Конкор** | Бисопролол | 2,5 / 5 / 10 мг | АГ, ИБС (стенокардия), ХСН |
| **Конкор АМ** | Бисопролол + амлодипин | 5+5 / 5+10 / 10+5 / 10+10 | АГ (switch-терапия) |
| **Конкор НСТ** | Бисопролол + ГХТЗ 6,25 мг | 2,5+6,25 / 5+6,25 / 10+6,25 | АГ |

### Принципиальные ограничения по инструкциям

**Конкор АМ — только switch-терапия.** Пациент сначала должен быть подобран на раздельных компонентах в тех же дозах.

**Конкор НСТ — стартовая комбинация.** По ОХЛП: начальная доза 2,5+6,25 мг 1 р/сут; при недостаточном эффекте — 5+6,25 мг. Предварительный подбор на раздельных компонентах не требуется.

**Максимальная доза бисопролола — 10 мг/сут.** Выше — вне инструкции.

**Ключевые противопоказания Конкора:**
- Острая / декомпенсированная ХСН
- AV-блокада II–III ст. без ЭКС, СССУ, СА-блокада
- Выраженная брадикардия (ЧСС <60), гипотензия (САД <100)
- Тяжёлая БА, тяжёлая ХОБЛ с обструкцией
- Тяжёлые нарушения периферического артериального кровотока
- Феохромоцитома без α-блокады, метаболический ацидоз

**Дополнительные противопоказания Конкор НСТ:** подагра, гипокалиемия, тяжёлая почечная недостаточность (СКФ <30), гиперчувствительность к сульфонамидам.

## 2. КАТЕГОРИИ КЕЙСОВ

### Категория 1 — Целевой (60%)
Пациент клинически подходит для одного из продуктов. Есть показание по инструкции, резерв по АД/ЧСС, ясное продуктовое решение. Возражение врача отрабатывается по структуре Признание → Переключение → Аргумент.

### Категория 2 — Пограничный (25%)
Формально аргументация возможна, но усилия несоразмерны результату. Путь наименьшего сопротивления — мягкий выход с возможностью вернуться.

### Категория 3 — Нецелевой (15%)
Пациент не подходит. Эталон — честный выход с клиническим обоснованием и запросом на других пациентов.

**Обоснование распределения:** медпред должен чаще побеждать через аргументацию (иначе разуверится в продукте), но регулярно проверяться на умение честно выйти (иначе будет бесплодно упираться).

**Главный риск, который нужно балансировать:** слишком легко обучившись уходить, медпред превратит это в отмазку от работы. Поэтому эталон нецелевого кейса должен содержать чёткое клиническое обоснование — иначе медпред будет уходить от любого сложного кейса.

Детальные критерии трёх категорий — в quality_criteria.md разделы 2, 3, 4.

## 3. ТИПОЛОГИЯ ПРОДУКТОВЫХ РЕШЕНИЙ

### Тип А — Конкор (монокомпонент)

#### А1 — Новое назначение Конкора
Пациент без ББ. Появилось показание для бисопролола.

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| АГ + симпатикотония | АГ, ЧСС 80–85, стрессы | Конкор 5 мг |
| Молодой гипертоник | АГ, 30–40 лет, ЧСС 90+, тревожность | Конкор 5 мг — ESH 2023: ЧСС >80 = показание |
| Пост-ИМ без ХСН | ФВ >50%, без стенокардии | Конкор 5 мг — вторичная профилактика |
| ФП + АГ (контроль ЧСС) | ЧСС не в цели, показание по АГ | Конкор (показание — АГ, контроль ЧСС — фармсвойство) |
| Добавление к конкурентной FDC | На Престансе/Эксфорже, ЧСС не в цели | Конкор поверх существующей FDC, **без её разборки** |

Пациент уже на Конкоре в субоптимальной дозе, ЧСС не в цели.

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| ИБС II ФК + АГ, Конкор 5 мг, ЧСС 72 | Резерв по АД есть | Конкор 10 мг |

#### А3 — Замена дженерика на Конкор
Пациент на неоригинальном бисопрололе, нестабильность эффекта (разброс ЧСС/АД между визитами).

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| ИБС + АГ на дженерике бисопролола 5 мг | Разброс 68–75 / 138–145 | Конкор 5 мг → стабилизация → (титрация при необходимости) |

#### А4 — Замена конкурентного ББ на Конкор
Пациент на другом ББ, есть клинический аргумент для switch.

| Конкурент | Показание для switch | Аргумент |
|-----------|---------------------|----------|
| Небиволол | ХСН | CIBIS-II (смертность −34%), зарегистрированное показание ХСН; SENIORS — только >70 лет, без достоверного снижения смертности |
| Метопролол | ХОБЛ, периферический атеросклероз | Селективность 75:1 vs 40:1, двойная элиминация |

### Тип Б — Конкор АМ (бисопролол + амлодипин)

#### Приоритеты портретов для Конкор АМ (КРИТИЧЕСКИ ВАЖНО)

**Основной портрет (генерируется как целевой):** **АГ + ИБС** — это центральный сценарий тренировки. Все типы Б1, Б2, Б3, Б4 в качестве целевых кейсов работают именно с этим портретом.

**Дополнительный портрет (генерируется как целевой):** АГ + сопутствующие коморбидности (СД, метаболический синдром) при наличии независимого клинического показания для бисопролола.

**Портрет, который НЕ используется как целевой:** **изолированная АГ без ИБС** (включая молодых гипертоников с симпатикотонией). Это **не клинический запрет** — Конкор АМ формально применим при изолированной АГ. Но это **не основной портрет** для тренировки, так как:
- В реальной практике у врача в первой линии при изолированной АГ — иАПФ/БРА + АК
- Тренировать медпреда продавать Конкор АМ при изолированной АГ — расходовать обучающий ресурс на непрофильный сценарий
- Для изолированной АГ с тахикардией остаётся целевым **Конкор-монотерапия** (тип А1)

**Если в кейсе появляется изолированная АГ + предложение Конкор АМ — это пограничный кейс.** Медпред должен признать, что формально аргументация возможна, но рациональнее переключиться на основной портрет (АГ + ИБС с не контролируемым АД/ЧСС).

#### Б1 — Перевод на Конкор АМ после оптимизации Конкора (АГ + ИБС, основной сценарий)

Потенциал Конкора оптимизируется или ЧСС уже в цели, остаётся проблема с АД — нужен амлодипин. Момент перехода зависит от клинического профиля и от позиции врача (см. ниже).

**Логика выбора момента (профиль-зависимая):**

Алгоритм терапии стабильной ИБС (КР МЗ РФ, таблица ПА3-5) — пошаговый, но это **опция, а не строгая рекомендация**: примечание прямо предписывает адаптировать его под индивидуальные особенности пациента, а сноска «a» допускает комбинацию **БАБ + ДГП-БКК уже на шаге 1** (с учётом коморбидности и инструкции к препарату).

При **АГ + ИБС со стабильной стенокардией I-II ФК и ЧСС >60 уд/мин** титрация бисопролола до целевой ЧСС 55–60 — **целесообразна** (ЕОК I A) и снижает частоту приступов. Это **один из легитимных шагов, а не единственный обязательный**: добавление дигидропиридина (контроль АД + антиангинальный эффект) — параллельно допустимая опция.

**Роль медпреда — давать возможности, не предписывать последовательность.** Канон речи: «есть Конкор в дозах 5 и 10 мг; при наличии гемодинамического резерва (АД выше цели, ЧСС позволяет) можно добавить амлодипин и затем перевести пациента на Конкор АМ — FDC, с преимуществами по приверженности и гибкой линейкой доз».

Развязка по профилю врача:
- **Врач открыт к оптимизации ББ** → развилка с явным правилом «когда какой путь»: (а) дотитровать Конкор до целевой ЧСС, затем при остаточном АД — амлодипин → Конкор АМ; **или** (б) при достаточном резерве добавить амлодипин сразу → Конкор АМ. Озвучить оба варианта.
- **Врач против ап-титрации ББ** → вести на добавление амлодипина → Конкор АМ; целевую ЧСС держать **контекстом**, не настаивая на дозовом максимуме ББ. Бисопролол остаётся инструментом контроля ЧСС (дотитровать можно позже или в составе Конкор АМ).
- **В любом целевом по АМ кейсе** мост до Конкор АМ + линейка доз должны прозвучать — независимо от того, какой путь ближе врачу.

При **АГ + ИБС без активной стенокардии** или **ЧСС уже в цели** — переход на Конкор АМ выполняется без обязательного дозового максимума Конкора.

При **АГ + ИБС со стенокардией III-IV ФК** — по КР МЗ РФ **сразу** назначается комбинация БАБ + ДГП-БКК для достижения ФК I. Старт с Конкора + амлодипина раздельно (в подобранных дозах) с переходом на Конкор АМ — клинически обоснованный путь.

**Switch-only:** Конкор АМ — перевод в **уже подобранных дозах** компонентов. ЧСС контролирует бисопролол, АД — оба компонента (амлодипин — по АД, не по ЧСС). 4 дозировки (5/5, 5/10, 10/5, 10/10) под подобранные дозы. Не стартовать Конкор АМ как инициальную терапию у наивного пациента.

| Сценарий | Профиль / логика | Продуктовое решение |
|----------|------------------|---------------------|
| ИБС II ФК + АГ, Конкор 10 мг, ЧСС 58, АД 156/94 | ЧСС в цели, резерв по АД | + амлодипин → Конкор АМ 10+5 |
| ИБС II ФК + АГ, Конкор 5 мг, ЧСС 74, АД 151/93, приступы; **врач против ↑ дозы ББ** | Резерв есть; ведём на FDC, ЧСС — контекст | + амлодипин (при резерве) → Конкор АМ (доза = подобранным компонентам); ЧСС параллельно можно дотитровать бисопрололом |
| тот же кейс, но **врач открыт к оптимизации ББ** | Развилка с правилом выбора | (а) ↑ Конкор до ЧСС-цели → +амло → АМ; **или** (б) +амло сразу → АМ. Озвучить оба |
| ИБС III-IV ФК + АГ, на ничём | КР МЗ РФ — старт с комбинации | Конкор + амлодипин раздельно → Конкор АМ |

#### Б2 — Объединение уже стоящих компонентов в Конкор АМ

Пациент получает бисопролол + амлодипин раздельно.

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| ИБС III ФК + АГ + СД, на амлодипине 5 мг, ББ нет | Добавить бисопролол = Конкор АМ 5+5 | Конкор АМ 5+5 |
| Тройная терапия РААС + амло + бисо | Упрощение схемы | Конкор АМ + РААС (2 препарата вместо 3) |

#### Б3 — Конкор АМ как финал многошаговой логики
Кейс начинается с другой проблемы, FDC — итоговый шаг.

| Сценарий | Этапы |
|----------|-------|
| Дженерик → Конкор → титрация → Конкор АМ | Трёхшаговая логика |

#### Б4 — Снижение дозы амлодипина под прикрытием бисопролола

**Строгое условие применимости:** у пациента есть **независимое клиническое показание для бисопролола** (ИБС, тахикардия, пост-ИМ, ХСН, симпатикотония с ЧСС >80). Без независимого показания для ББ этот тип **не применяется** — случай уходит в пограничные или нецелевые.

**Сценарий:** пациент на амлодипине 10 мг (в монотерапии или с РААС раздельно; не в составе конкурентной FDC), развились периферические отёки. **Одновременно есть показание для бисопролола** — например, стабильная стенокардия с ЧСС не в цели, или пост-ИМ, или тахикардия на фоне АГ.

**Главный аргумент:** снижение дозы амлодипина с 10 мг до 5 мг уменьшает частоту отёков (дозозависимый эффект из инструкции амлодипина).

**Роль бисопролола:** компенсирует возможную потерю гипотензивного эффекта от снижения дозы АК **и** закрывает собственное клиническое показание.

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| ИБС II ФК + АГ + амлодипин 10 мг, отёки, ЧСС 78 | Есть показание для ББ по ИБС | Амло 10 → 5 мг + добавить бисопролол = Конкор АМ 5+5 |
| Пост-ИМ + АГ + амлодипин 10 мг, отёки, ЧСС 74 | Есть показание для ББ по вторичной профилактике | Амло 10 → 5 мг + добавить бисопролол = Конкор АМ 5+5 |

**Граница с Типом В3 (Конкор НСТ):** если отёки развиваются даже на минимальной дозе амлодипина 2,5 мг — это не дозозависимый эффект, а непереносимость АК. Такой пациент идёт на Конкор НСТ (Тип В3), а не на Конкор АМ.

### Тип В — Конкор НСТ (бисопролол + ГХТЗ 6,25 мг)

#### В1 — АГ + потребность в диуретике + тахикардия
Пациент без ББ, нужен контроль ЧСС + мягкий диурез.

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| АГ + задержка жидкости + ЧСС 82 | На ИАПФ 20 мг | Конкор НСТ 5+6,25 |

#### В2 — Конкор НСТ при страхе метаболических эффектов диуретика
Врач боится ГХТЗ.

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| АГ + МС/преддиабет, врач против тиазидов | ГХТЗ 6,25 мг — субдиуретическая доза | Конкор НСТ |

#### В3 — АД не в цели, ЧСС в цели, АК невозможен
Конкор 10 мг уже стоит, увеличивать нельзя (брадикардия), амлодипин невозможен (отёки в любой дозе).

| Сценарий | Нозология | Продуктовое решение |
|----------|-----------|---------------------|
| АГ, Конкор 10 + РААС, ЧСС 58, АД 148/90, отёки на АК в анамнезе | Замена Конкор 10 на Конкор НСТ 10+6,25 | Конкор НСТ 10+6,25 |

#### Правило Конкор НСТ при коморбидности

Конкор НСТ зарегистрирован **только для АГ**. Однако у пациента с АГ могут быть сопутствующие ИБС или ФП. В этом случае:

- ✅ **Разрешено:** АГ + ИБС (коморбидность), нужен контроль АД, есть потребность в диуретике → Конкор НСТ. Позиционирование: препарат лечит АГ по инструкции; бисопролол в составе дополнительно работает по ИБС как фармакологическое свойство
- ✅ **Разрешено:** АГ + ФП (коморбидность), нужен контроль АД → Конкор НСТ. Аналогичная логика
- ❌ **Запрещено:** ИБС без АГ → Конкор НСТ не показан (нет показания)
- ❌ **Запрещено:** ФП без АГ → Конкор НСТ не показан
- ❌ **Запрещено:** ХСН → Конкор НСТ не показан ни при каких обстоятельствах (тиазидный диуретик противопоказан при тяжёлой ХСН)

Это правило компенсирует континуум-инфографику слайда 2 PPTX В.1, где Конкор НСТ визуально размещён рядом с ИБС/ФП без явного указания на обязательность АГ как первичного показания.

### Тип Г — Нецелевой пациент

Единственный тип, где правильный ответ — не продукт, а вопрос врачу о других пациентах.

**Г1 — Нет показания для бисопролола**
Нет ИБС, нет тахикардии >80, нет ХСН, нет пост-ИМ, нет симпатикотонии. Обсуждать Конкор не на чем.

**Г2 — Прямое противопоказание**
AV-блокада II–III ст., выраженная брадикардия, тяжёлая БА/ХОБЛ, декомпенсированная ХСН, гипотензия. Конкор противопоказан.

**Г3 — Оптимальный контроль на текущей терапии**
АД и ЧСС в цели, симптомов нет, переносимость хорошая, приверженность высокая. Менять нечего.

**Г4 — «Запечатан» в конкурентной экосистеме**
На конкурентной FDC (Престанс, Эксфорж), ББ не показан ИЛИ уже стоит конкурентный ББ в оптимальной дозе. Врач лоялен конкуренту.

**Г5 — Ситуация вне компетенции медпреда**
Терминальная стадия другого заболевания, острое состояние, требующее консилиума.

**Г6 — Вне зарегистрированных показаний Конкора**
Изолированная ФП без АГ/ИБС/ХСН, контроль ЧСС при тиреотоксикозе, IST — клинически бисопролол работал бы, но показания нет в инструкции.

**Г7 — Вне инструкции по дозам или комбинациям**
Необходимость дозы >10 мг, дозировки вне зарегистрированных для FDC, противопоказанные комбинации.

Детализация в quality_criteria.md раздел 2.

## 7. СТРУКТУРА ЭТАЛОННОГО ОТВЕТА

### Для целевого кейса: Признание → Переключение → Аргумент

**Признание** (1–2 предложения) — конкретное рациональное зерно позиции врача. Не формальное «понимаю вас», а конкретное указание на логику, которая верна.

**Переключение** (2–4 предложения) — опора на данные: клинреки, исследования, фармакология. Указывает фактор, который врач упустил или недооценил. Использует сквозные аргументы (раздел 8).

**Аргумент** (2–4 предложения) — конкретное продуктовое решение (препарат, доза, форма), обоснование через параметры пациента из кейса, следующий шаг при необходимости.

### Для пограничного кейса: Признание + Оценка + Переключение

**Признание** — «Формально аргументация возможна, но…» + фактор, делающий путь непродуктивным (категоричность врача, слабое клиническое обоснование, ценовой барьер).

**Переключение** — запрос к врачу на других пациентов нужного профиля, с сохранением возможности вернуться к этому пациенту позже.

### Для нецелевого кейса: Признание + Переключение

**Признание** — «Этот пациент сейчас не целевой для нашего продукта» + конкретное клиническое обоснование (какое противопоказание / отсутствие показания / оптимальный контроль / экосистема конкурента).

**Переключение** — конкретный запрос с **предметно сформулированным профилем**: «Есть ли у вас пациенты с неконтролируемой ЧСС?» / «…с сохраняющейся стенокардией на текущей терапии?» / «…кому нужно упрощение схемы приёма?»

### Общие требования ко всем эталонам

- Не выходит за рамки зарегистрированных показаний Конкора
- Не содержит медицинских советов от медпреда (медпред не назначает, не отменяет, не дозирует)
- Комплаентно для фармкомпании
- Использует сквозные аргументы из раздела 8
- Не сравнивает Конкор с конкурентами без данных исследований

## 9. МАТРИЦА ВАЛИДНОСТИ КОМБИНАЦИЙ

Любой кейс = **[Продуктовое решение] × [Возражение] × [Нозология] × [Профиль врача]**.

### Валидные комбинации

| Возражение | Допустимые продуктовые решения |
|------------|-------------------------------|
| В1 (проще добавить другое) | А1, А2 |
| В2 (не хочу добавлять таблетку) | А1 (+ аргумент приверженности); Б1, Б2 (Конкор АМ упрощает) |
| В3 (зачем FDC) | Б1, Б2, Б3, Б4, В1, В2, В3 |
| В4 (побочки ББ) | А1, А2, А4 |
| В5 (другой ББ) | А4 |
| В6 (дженерик работает) | А3 |
| В7 (потолок) | А4 (замена ББ), Б1, Б4 (добавить АК или решить отёки), В3 (НСТ при невозможности АК) |
| В8 (ББ не нужны) | А1 (сузить аудиторию до показаний); пограничный кейс, если показание слабое |
| В10а (скепсис к оригиналам) | А1–А4 (аргумент стабильности и доказательной базы на оригинале) |
| В10б (ценовой барьер пациента) | Пограничный кейс |

### Невалидные комбинации (исключать)

- В3 (против FDC) + А1–А4 (Конкор моно) — возражение бессмысленно
- В5 (другой ББ) + Б1–Б4 (Конкор АМ) — вопрос не про FDC, а про ББ
- В6 (дженерик) + Б1–Б4 или В1–В3 — пациент не на бисопрололе, неприменимо
- Конкор НСТ + пациент с подагрой / гипокалиемией / СКФ <30
- Конкор АМ + пациент с отёками на АК в анамнезе — путь к Конкор НСТ
- Конкор АМ, если пациент не подобран на раздельных компонентах
- Доза >10 мг бисопролола — всегда невалидно
