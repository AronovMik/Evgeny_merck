### 2026-04 — Рецензирование медицинских постов в Telegram (Merck — Конкор/Конкор АМ/Конкор НСТ)
**Файл:** [`2026-04_telegram-posts-review-merck.md`](./2026-04_telegram-posts-review-merck.md)
**Период:** апрель – май 2026 (Apr 1, Apr 28, May 8).
**Тема:** рецензирование Telegram-постов и видео-концептов для канала, спонсируемого Merck. Установлен формат рецензии (фактчекинг → compliance → редакторика → Merck-позиционирование). Аудитория — терапевты и кардиологи.
**Препараты:** Конкор, Конкор АМ, Конкор НСТ.
**Гайдлайны:** КР МЗ РФ (СтИБС, АГ), ESC CCS 2024, AHA/ACC 2023; для CAC — SCCT CAC-DRS 2018, MESA.
**Содержание:**
- Пост 1 (стенокардия + АГ, комбо ББ + ДГП-АК): закрыт FDC-gap через антиангинальный эффект Конкор АМ по Скибицкому; критический разбор внутригрупповых vs межгрупповых p-значений; замена слабой ссылки Spaulding 1997 на КР МЗ РФ + AHA/ACC 2023 + JACC 2024.
- Пост 2 (формулировка про Конкор как ББ первой линии): шлифовка фразы; compliance-замена «препарат выбора» на «оптимальный выбор / один из предпочтительных»; верификация цифры β1/β2 — подтверждено только 75:1 (Smith & Teitler 1999), цифра «103:1» в указанных источниках не найдена.
- Видео-блок с KOL (Ткачёва, Родионов): отказ от «препарат-центричных» тем в пользу 12 клинических дилемм кардиолога (ХСН: целевая доза/ФВ/коморбидность/пожилой; после ИМ; АГ+ИБС с фокусом на ORBITA, FDC; перименопауза + Конкор-НСТ; оригинал vs дженерик; ФП+ХСН).
- Пост про CAC: разъяснение логики порога CAC>0 (warranty period); правка стиля абзаца про MESA; критический разбор раздела «Клинические рекомендации» — ссылки 7, 8, 1 атрибутированы неверно; уточнение по российским КР (специфических порогов по CAC нет).

**Установленные принципы (применимы и в других задачах):**
- Конкретные фармакологические числа (селективность, аффинность) — верифицировать против первоисточников, не маркетинговых слайдов.
- FDC-аргумент строится на клинических конечных точках (антиангинальный эффект, вариабельность АД, PWV/AIx), не на абстрактной приверженности.
- Скибицкий — только для антиангинального эффекта Конкор АМ; не для доказательства превосходства FDC vs free combo тех же компонентов (там сравниваются разные схемы).
- Compliance-маркеры: «препарат выбора», «золотой стандарт» — заменять на нейтральные формулировки с обоснованием.
- Темы KOL-контента строить от клинической дилеммы; препарат — инструмент, не герой.
- Российские КР по CAC специфических порогов и интервалов не содержат — не претендовать.
- Формат рецензии: таблица `# | Фрагмент | Проблема | Тип | Правка` + итоговая оценка 🟢/🟡/🔴. Пользователь правит сам — рецензент даёт точечные флаги и готовые формулировки, не переписывает целиком.

**Когда подгружать:**
- При рецензировании любого нового Telegram-поста для канала Merck.
- При работе с FDC-аргументацией (Конкор АМ vs free combo) — особенно если в тексте фигурирует Скибицкий.
- При спорах о β1-селективности бисопролола и конкретных числах селективности.
- При работе с темами KOL-видео — для калибровки от «препарат-центричных» к «клинически-центричным».
- При работе с темой CAC-скрининга и первичной профилактики.

### 2026-03 — Клинические случаи с препаратами семейства Конкор
**Файл:** [`2026-03_klinicheskie-sluchai-konkor.md`](./2026-03_klinicheskie-sluchai-konkor.md)
**Период:** 21–30 марта 2026.
**Тема:** рецензирование готовых клинических случаев под позиционирование Конкор АМ + критический разбор постов Telegram-канала для врачей. Команда «двух кардиологов + маркетолог»; задача — закрыть двусмысленности до того, как их задаст аудитория.
**Препараты:** Конкор АМ (преимущественно), Конкор, Конкор НСТ; общая часть по бисопрололу.
**Гайдлайны:** КР МЗ РФ и ESC/ESH (рамка указывается явно в каждом фрагменте).
**Содержание:**
- Case 1 (AS, мужчина 50 лет, АГ) — путь к Конкор АМ через добавление бисопролола к лозартану + амлодипину; стратификация по SCORE2; ЧСС 87 вместо явной тахикардии.
- Case 2 (AC, женщина 67 лет, ИБС/ИМ в анамнезе) — согласование анатомии LAD/LCx, патентный стент в ПНА, HFpEF и SGLT2, HbA1c для закрытия темы СД2, дисклеймер титрования при субтерапевтических дозах.
- Case 4 (WS, мужчина 58 лет, АГ + ХОБЛ) — кардиоселективность бисопролола при GOLD 1; коррекция липидов по Фридевальду; SpO2 96% для исключения гипоксии.
- Case 1 (CE, женщина 38 лет, молодая АГ) — обоснование комбинации со старта по КР МЗ РФ (≥3 ФР); контрацептивы как нейтральная ремарка; «undertreated» вместо «newly diagnosed»; non-dipper формально не входит в перечень ФР по КР МЗ РФ.
- Case 3 (lipid recalc) — коррекция общего холестерина по Фридевальду при сохранении ЛНП.
- 5 постов Telegram: фенотипы тахикардии (выбор второго блока про разделение фенотипов); «тахикардия в 18 → ХСН в 40» (схема титрования бисопролола применима только при ХСН); клинический кейс ожирения (HbA1c — вспомогательный, не диагностический критерий предиабета); диагностика и лечение НЖТ 2025 (ФП в КР МЗ РФ ведётся отдельно; ивабрадин — только при IST).

**Установленные принципы (применимы и в других задачах):**
- Конкор АМ — только switch с двух монокомпонентов; кейс должен начинаться с пациента, уже получающего бисопролол + амлодипин раздельно.
- Конкор НСТ — только АГ лёгкой/умеренной степени, без ИБС/ХСН.
- В обучающих кейсах высоконормальная ЧСС лучше явной тахикардии: расширяет показания и не создаёт ложного паттерна «бисо нужен только при >100».
- Целевые значения ЧСС/АД на слайде + «consider switching … once targets are achieved» — снимает регуляторный риск без прямого совета медпреда.
- Все «соседние» темы (статины, вес, СД) — адресовать одной строкой, чтобы аудитория не уводила дискуссию.
- HbA1c — **вспомогательный**, не диагностический критерий предиабета по КР МЗ РФ и ВОЗ; формальные критерии — НГН 6,1–6,9 ммоль/л или ПГТТ.
- Россия по SCORE2 — страна **очень высокого** риска (порог ≥7,5% для очень высокого), не умеренного.
- Числа в клиническом документе должны быть внутренне согласованы (Фридевальд, ЧСС в осмотре и на ЭКГ, SpO2 и предполагаемая причина тахикардии).

**Когда подгружать:**
- При разборе любого нового клинического кейса для Конкор АМ или Конкор НСТ.
- При рецензировании постов / материалов по тому же паттерну «закрыть двусмысленности до вопроса аудитории».
- При вопросах по позиционированию бисопролола (β1-селективность, ХОБЛ, целевые ЧСС/АД).
- При работе с липидным профилем и стратификацией ССР по SCORE2 для российской аудитории.
