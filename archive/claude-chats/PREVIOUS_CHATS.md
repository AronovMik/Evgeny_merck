# PREVIOUS_CHATS — индекс перенесённых чатов

> **Назначение.** Лёгкое оглавление всех перенесённых из claude.ai чатов. Читается Claude в начале каждой сессии, чтобы знать, какие исторические контексты доступны. Сами файлы чатов **подгружаются только по команде Евгения** — например: «подтяни чат про клинические случаи», «загрузи архив по KOL-ответам».
>
> **Когда обновляется.** При переносе каждого нового чата сюда добавляется одна запись по шаблону ниже.

---

## Шаблон записи

```markdown
### YYYY-MM[-DD] — Краткое название чата
**Файл:** [`имя-файла.md`](./имя-файла.md)
**Период:** даты, охваченные чатом

**Когда подгружать:** при каких типах запросов этот чат полезен как контекст.
```

### 2026-04–05 — Тренажёр клинических случаев для медпредов
**Файл:** [`2026-04-05_trenazher-klinicheskih-sluchaev-medpred.md`](./2026-04-05_trenazher-klinicheskih-sluchaev-medpred.md)
**Период:** 11 апреля — 6 мая 2026.
**Тема:** проектирование AI-тренажёра для тренировки медпредов по портфелю Конкор. Конечная идея — виртуальный генератор клинических кейсов в Merck myGPT Suite (Langdock, Sonnet 4.6), где медпред получает кейс, отрабатывает возражение врача, получает разбор и эталон по структуре «Признание → Переключение → Аргумент».
**Препараты:** Конкор, Конкор АМ, Конкор НСТ, Конкор Кор (вся линейка).
**Гайдлайны:** КР МЗ РФ — основная рамка (АГ 2024, стабильная ИБС 2024, ХСН 2024, ФП). Международные гайдлайны исключены из текущей итерации.
**Содержание:**
- Типология v2.0: 4 типа продуктовых решений (А1–А4 / Б1–Б4 / В1–В3 / Г1–Г7), 14 нозологий, 9 типов возражений (В1–В10), 9 профилей врача, матрица валидных комбинаций, 25 кейсов.
- 3 категории кейсов (60/25/15): целевой / пограничный / нецелевой. Цель — научить распознавать нецелевых, но не превращать уход в отмазку.
- 16 проверенных сквозных аргументов с прослеживаемыми первоисточниками (КР МЗ РФ, инструкции, PPTX Мерк, PubMed). Ключевые: целевая ЧСС 55-60 (ЕОК I A), Terol 1990 (88% переносили 10 мг), CIBIS-II, Hostalek 2016 (95% приверженность на FDC), Rasmussen 2025 (датское ЭД, PMID 40796029), Григорьева 2010 (75% не достигают ЧСС на Бипроле при ИБС+ХОБЛ), Tian 2020 (HR смертности 0,84 = −16% на оригинале), COMET (Lancet 2003, тартрат), Chung 2022 (пост-ИМ + ХОБЛ, HR 0,90 vs карведилол), Скибицкий 2015 (АГ+ИБС+МС: приступы 0,2 vs 1,03 на FDC vs свободной комбинации), мета-анализы БАБ+АК (Heidenreich 1999, Klein 2002, Belsey 2015).
- 4 группы опор по ключевым возражениям (дженерики / небиволол / карведилол / метопролол) с правилом многосоставности (≥2 опоры в эталоне).
- Два агента: авторский (system_prompt.md, для Евгения как медсоветника) и медпредский (medrep_prompt.md, для пилотных пользователей) с двухфазным диалогом.
- Использован стек: Claude Opus 4.7 + Claude Code (анализ ~600 страниц клинреков) + Claude Design + Merck myGPT Suite (Sonnet 4.6).
- Презентационные материалы: 7 шагов для топ-менеджмента (хронология действий, не «достижения»), 7 слайдов для коллег-медсоветников, 8 бэкап-слайдов с расшифровкой методологии.

**Установленные принципы (применимы и в других задачах):**
- **Иерархия источников:** КР МЗ РФ → инструкции → корпоративные PPTX → первичные публикации. Ничего по памяти, каждая цифра — со ссылкой.
- **Принцип встраивания в решение врача:** медпред НЕ оспаривает клиническое решение, НЕ предписывает последовательность шагов. Сценарий 1 (амлодипин уже у пациента/в плане) — встраиваемся в решение. Сценарий 2 (только моно-Конкор) — продуктовая цепочка.
- **Запрет на перечисление антиангинальных альтернатив** (нитраты, ивабрадин, ранолазин, триметазидин) — это вне роли медпреда.
- **Конкор НСТ при коморбидности:** разрешён при АГ+ИБС или АГ+ФП; запрещён при ИБС/ФП без АГ и при ХСН.
- **Изолированная АГ:** целевой только для Конкор-монотерапии; для Конкор АМ — пограничный/нецелевой (не основной портрет).
- **Стилистические запреты:** «метаболически нейтрален», «субдиуретическая доза», «88% достигают 10 мг» — искажения, не использовать. Можно: 75% / 16% (по проверенным первоисточникам).
- **Двухфазный диалог:** Фаза 1 (кейс без эталона) → ответ медпреда → Фаза 2 (разбор + обязательный эталон в финале). Тип 2 (уточняющие вопросы) — без эталона. Агент НЕ отыгрывает врача в дополнительном диалоге.
- **Многосоставность аргументов:** при ключевых возражениях эталон использует ≥2 опоры. Шкала тона разбора: А/Б/В/Г.
- **Обязательная ротация подтипов:** ~1 из 5 целевых кейсов на Конкор АМ — стенокардия III-IV ФК; не менее 1 из 4 — тип Б2 (пациент уже на бисо+амло раздельно).
- **Метод переносим** на любую продуктовую линейку компании: та же типология, тот же приоритет источников, тот же двухфазный pipeline.

**Когда подгружать:**
- При продолжении работы над тренажёром клинических кейсов (текущая итерация на паузе из-за проблемы контекста в myGPT Suite — ждём ответа от IT Мерк).
- При создании аналогичного AI-тренажёра для другой продуктовой линейки.
- При обсуждении методологии AI transformation с топ-менеджментом / коллегами-медсоветниками.
- При вопросах про верификацию источников в фармацевтических AI-инструментах.
- При работе с любым новым клиническим кейсом для Конкор АМ.
- При обсуждении ограничений контекстного окна в корпоративных LLM-платформах (Langdock в Мерк).

### 2026-03 — Клинические случаи с препаратами семейства Конкор
**Файл:** [`2026-03_klinicheskie-sluchai-konkor.md`](./2026-03_klinicheskie-sluchai-konkor.md)
**Период:** 21–30 марта 2026.
**Тема:** рецензирование готовых клинических случаев под позиционирование Конкор АМ + критический разбор постов Telegram-канала для врачей. Команда «двух кардиологов + маркетолог»; задача — закрыть двусмысленности до того, как их задаст аудитория.
**Препараты:** Конкор АМ (преимущественно), Конкор, Конкор НСТ; общая часть по бисопрололу.
**Гайдлайны:** КР МЗ РФ и ESC/ESH (рамка указывается явно в каждом фрагменте).
**Содержание:**
- Case 1 (AS, мужчина 50 лет, АГ) — путь к Конкор АМ через добавление бисопролола к лозартану + амлодипину; стратификация по SCORE2; ЧСС 87 вместо явной тахикардии.
- Case 2 (AC, женщина 67 лет, ИБС/ИМ в анамнезе) — согласование анатомии LAD/LCx, патентный стент в ПНА, HFpEF и SGLT2, HbA1c для закрытия темы СД2, дисклеймер титрования при субтерапевтических дозах.
- Case 4 (WS, мужчина 58 лет, АГ + ХОБЛ) — кардиоселективность бисопролола при GOLD 1; коррекция липидов по Фридевальду; SpO2 96% для исключения гипоксии.
- Case 1 (CE, женщина 38 лет, молодая АГ) — обоснование комбинации со старта по КР МЗ РФ (≥3 ФР); контрацептивы как нейтральная ремарка; «undertreated» вместо «newly diagnosed»; non-dipper формально не входит в перечень ФР по КР МЗ РФ.
- Case 3 (lipid recalc) — коррекция общего холестерина по Фридевальду при сохранении ЛНП.
- 5 постов Telegram: фенотипы тахикардии (выбор второго блока про разделение фенотипов); «тахикардия в 18 → ХСН в 40» (схема титрования бисопролола применима только при ХСН); клинический кейс ожирения (HbA1c — вспомогательный, не диагностический критерий предиабета); диагностика и лечение НЖТ 2025 (ФП в КР МЗ РФ ведётся отдельно; ивабрадин — только при IST).

**Установленные принципы (применимы и в других задачах):**
- Конкор АМ — только switch с двух монокомпонентов; кейс должен начинаться с пациента, уже получающего бисопролол + амлодипин раздельно.
- Конкор НСТ — только АГ лёгкой/умеренной степени, без ИБС/ХСН.
- В обучающих кейсах высоконормальная ЧСС лучше явной тахикардии: расширяет показания и не создаёт ложного паттерна «бисо нужен только при >100».
- Целевые значения ЧСС/АД на слайде + «consider switching … once targets are achieved» — снимает регуляторный риск без прямого совета медпреда.
- Все «соседние» темы (статины, вес, СД) — адресовать одной строкой, чтобы аудитория не уводила дискуссию.
- HbA1c — **вспомогательный**, не диагностический критерий предиабета по КР МЗ РФ и ВОЗ; формальные критерии — НГН 6,1–6,9 ммоль/л или ПГТТ.
- Россия по SCORE2 — страна **очень высокого** риска (порог ≥7,5% для очень высокого), не умеренного.
- Числа в клиническом документе должны быть внутренне согласованы (Фридевальд, ЧСС в осмотре и на ЭКГ, SpO2 и предполагаемая причина тахикардии).

**Когда подгружать:**
- При разборе любого нового клинического кейса для Конкор АМ или Конкор НСТ.
- При рецензировании постов / материалов по тому же паттерну «закрыть двусмысленности до вопроса аудитории».
- При вопросах по позиционированию бисопролола (β1-селективность, ХОБЛ, целевые ЧСС/АД).
- При работе с липидным профилем и стратификацией ССР по SCORE2 для российской аудитории.
