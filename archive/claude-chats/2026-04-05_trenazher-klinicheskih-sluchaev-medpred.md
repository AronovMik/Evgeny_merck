# Тренажёр клинических случаев для медпредов

> **Источник:** перенесено из другого аккаунта Claude по просьбе Евгения (2026-05-22).
> **Период работы в исходном чате:** 11 апреля — 6 мая 2026.
> **Назначение:** проектирование AI-тренажёра для тренировки медпредов по портфелю Конкор. Конечная идея — виртуальный генератор клинических кейсов в Merck myGPT Suite (Langdock, Sonnet 4.6), где медпред получает кейс, отрабатывает возражение врача, получает разбор и эталон.

---

## Структура исходного чата (по этапам)

### Этап 1 — Постановка задачи (11 апреля)
- Идея: AI-тренажёр для медпредов по продвижению Конкор, Конкор АМ, Конкор НСТ кардиологам.
- Формат: пока текст, потом голос. Нужна типология врачей.
- Уточнено: 9 кейсов из тренинговых материалов СНГ и РФ переданы Claude как референс.

### Этап 2 — Типология (11 апреля)
- Первая классификация по продуктовым решениям (А1–А4 / Б1–Б4), возражениям (В1–В10), нозологиям, профилям врача.
- Выявлены пробелы: Конкор НСТ полностью отсутствовал, не было кейсов про конкурентные FDC, отёки на амлодипине, ФП, пост-ИМ без ХСН, изолированную АГ с тахикардией, спортсменов, тройную терапию, удержание от отмены.
- Добавлены Тип Г (нецелевой пациент) и навык «выход и переключение».

### Этап 3 — Критерии качества (17 апреля)
- Зафиксировано три категории кейсов: целевой / пограничный / нецелевой (60/25/15).
- Принципы: реалистичность цифр, отсутствие «ловушек» в анамнезе, соответствие инструкциям, обоснованность возражений, однозначность правильного решения.
- Уточнено: пункт 3.3 (off-label) перенесён из пограничных в нецелевые. Конкор не обсуждается вне зарегистрированных показаний (АГ, ИБС, ХСН).

### Этап 4 — Архитектура (17 апреля)
- Решено отказаться от симулятора врача и оценки, оставить только генерацию качественных кейсов с эталонным ответом по структуре «Признание → Переключение → Аргумент».
- Платформа: Merck myGPT Suite (Langdock).
- Один агент, не три параллельных. Системный промпт + база знаний.

### Этап 5 — Аудит типологии и системный промпт (17 апреля)
- Аудит typology v1.0: 4 правки, 4 синхронизации с quality_criteria.
- Создан **typology_v2.md** — 25 кейсов, обновлённый Тип Г (7 подтипов), В10 (ценовое возражение), удалено В9.
- Создан **system_prompt.md** (~1400 слов) для авторского агента.

### Этап 6 — Промпт для Claude Code (17 апреля)
- Принято решение: анализ клинреков и инструкций — в Claude Code, не в чате.
- Источники: КР МЗ РФ (АГ, ИБС, ХСН, ФП — без ОКС), инструкции Конкор/Конкор АМ/Конкор НСТ, PPTX Мерк (CLM, vs дженерики, vs ББ, портреты).
- Создан **claude_code_prompt.md** (~3500 слов): 12 разделов, 5 выходных артефактов (arguments_table, arguments_candidates, patient_portraits, competitive_messaging, conflicts_log).

### Этап 7 — Результаты Claude Code и валидация (17–18 апреля)
- Получены 5 артефактов + analysis_summary + inventory.
- Аудит работы Claude Code: дисциплина источников соблюдена, BICS / BLOCK-COPD / Chung 2022 корректно интегрированы.
- Критические находки:
  - Аргумент 11 (ББ уменьшают отёки от АК) — удалён, нет RCT.
  - Аргумент 12 — нужна сверка со страницами 10 и 22 КР АГ 2024.
  - Аргумент 9 (датское ЭД, Rasmussen 2025, PMID 40796029) — подтверждён.
  - Аргумент 2 (88% на 10 мг) — Terol 1990, формулировка «88% хорошо переносили 10 мг», не «достигают через титрацию».
  - Аргумент 14 (COMET) — подтверждено: метопролола тартрат, не сукцинат (Lancet 2003, DOI 10.1016/S0140-6736(03)13800-7). Основной аргумент vs карведилол — Chung 2022.
- Тип Б4 переформулирован: «снижение дозы амлодипина под прикрытием бисопролола» (требует независимого показания для ББ).
- Правило Конкор НСТ: разрешён при АГ + коморбидности (ИБС/ФП), запрещён при ИБС/ФП без АГ и при ХСН.

### Этап 8 — Цифры 75% / 16% vs дженерики (22 апреля)
- Найдены первоисточники: Григорьева 2010 (75% не достигают целевой ЧСС на Бипроле, ИБС+ХОБЛ) и Tian 2020, Scientific Reports (HR смертности 0,84 — 16% снижение).
- Зафиксированы как валидные с короткими корпоративными формулировками для речи медпреда.

### Этап 9 — Промпт для медпредов (23 апреля)
- Создан **medrep_prompt.md** для отдельного агента (пользователи — медпреды, не автор).
- Двухфазный диалог: Фаза 1 (кейс без эталона) → ответ медпреда → Фаза 2 (разбор + эталон).
- Упрощённая клиника: без электролитов, ИММ, Холтера с цифрами, КАГ, липидов до запятой. АД/ЧСС/ФВ — оставлены.

### Этап 10 — Разнообразие клинических деталей (23 апреля)
- Возраст: ИБС/АГ 45–75, ХСН 50–76, пост-ИМ 42–72, молодая АГ с тахикардией 28–42, пожилой 70–78.
- АД и ЧСС — диапазоны с уточнением: ЧСС в цели при ИБС I-II ФК = 55–60 (КР МЗ РФ, УУР А, УДД 5).
- Профессии и обстоятельства — мягко, с маркерами для БАБ (стресс, кофе, симпатикотония).

### Этап 11 — Многосоставность аргументов (26 апреля)
- Введён принцип: при ключевых возражениях эталон использует ≥2 опоры из группы.
- 4 группы опор: дженерики (4), небиволол (3), карведилол (3 — без COMET-нюанса), метопролол (3 — кратность только для тартрата).
- 4-уровневая шкала тона разбора ответа медпреда: А (все опоры) / Б (большинство) / В (одна) / Г (ни одной).

### Этап 12 — Дозировки, разграничение пограничный/нецелевой, запрет на коды (26–27 апреля)
- Дозировки обязательно в эталоне: Конкор АМ 5/5, 5/10, 10/5, 10/10; Конкор НСТ 2,5/5/10 + 6,25 ГХТЗ; Конкор 2,5/5/10 + Конкор Кор 2,5.
- Различительный критерий: пограничный = есть клиническая зацепка + внешний фактор; нецелевой = зацепки нет.
- Запрет на технические коды (А1–А4, Б1–Б4, В1–В10, Г1–Г7) в речи медпреда.
- Запрет на номер кейса в Фазе 1.
- Запрет на раскрытие категории кейса до Фазы 2.

### Этап 13 — Адресация сохраняющихся приступов стенокардии (27 апреля)
- Принцип: «вы уже приняли решение → я предлагаю улучшение того, что вы решили».
- Развилка по сценариям:
  - Сценарий 1 (амлодипин уже в плане врача / у пациента) → встраиваемся в решение, без оспаривания последовательности.
  - Сценарий 2 (только Конкор, амло не упоминается) → можно строить продуктовую цепочку «оптимизация Конкора → амло → Конкор АМ».
- Запрет на перечисление антиангинальных альтернатив (нитраты, ивабрадин, ранолазин, триметазидин) в обоих сценариях.
- Изолированная АГ выведена из активной зоны для Конкор АМ (нецелевой/пограничный).

### Этап 14 — Скибицкий 2015 как аргумент 17 (27 апреля)

### Этап 17 — Тонкая настройка двухфазного диалога (6 мая)
- Три типа реакции медпреда: Тип 1 (ответ → эталон), Тип 2 (уточняющий вопрос → ответ без эталона), Тип 3 (новый кейс / смена темы).
- Решение: НЕ давать агенту отыгрывать врача в дополнительном диалоге (Тип 2б отменён).
- Эталон всегда финальный блок в Фазе 2, без исключений.
- Информирование медпреда в конце Фазы 1: «Если хотите уточнить детали кейса или данные по препаратам — спрашивайте, отвечу».

## Установленные принципы (применимы и в других задачах)

### Методология верификации источников
- Приоритет: **КР МЗ РФ → инструкции препаратов → корпоративные материалы Мерк (PPTX) → первичные публикации**.
- «Ничего по памяти» — каждая цифра должна иметь прослеживаемый первоисточник.
- При конфликте между слоями побеждает более высокий приоритет.
- Статусы аргументов: «Проверено по первоисточнику» / «Проверено по корпоративному материалу» / «Требует проверки» / «Неприменим».
- Только аргументы со статусом «Проверено» используются в эталонных ответах генератора.

### Архитектура AI-тренажёра
- Один агент в myGPT Suite, без оркестрации между несколькими агентами (Langdock не поддерживает).
- Системный промпт — оперативная логика (как генерировать кейс, играть фазы, оценивать).
- База знаний (RAG) — справочный материал (типология, аргументы, портреты, критерии).
- Двухфазный диалог: Фаза 1 (кейс без эталона) → ответ медпреда → Фаза 2 (разбор + эталон).

### Структура эталонного ответа
- **Признание → Переключение → Аргумент** для целевых кейсов.
- Для нецелевых: признание + конкретный запрос на переключение на другого пациента.
- Для пограничных: признание + оценка + переключение.
- Эталон всегда адресует все клинически значимые проблемы из портрета пациента.

### Принцип встраивания в решение врача
- Медпред НЕ оспаривает клиническое решение врача и НЕ предписывает последовательность шагов.
- Сценарий 1 (врач уже планирует амлодипин / пациент уже на бисо+амло) — встраиваемся: «вы планируете → рассмотрите Конкор АМ как FDC».
- Сценарий 2 (только Конкор, амло не упоминается) — можно строить продуктовую цепочку.
- Запрет на перечисление антиангинальных альтернатив (нитраты, ивабрадин, ранолазин, триметазидин) — это вне роли медпреда.

### Многосоставность аргументов
- При ключевых возражениях эталон обязан использовать ≥2 опоры из группы.
- 4 группы опор: дженерики (4 опоры), небиволол (3), карведилол (3), метопролол (3).
- Шкала тона разбора ответа медпреда: А (все) / Б (большинство) / В (одна) / Г (ни одной).

### Категории кейсов (60/25/15)
- **Целевой 60%** — есть клиническое продуктовое решение, отрабатывается возражение.
- **Пограничный 25%** — есть клиническая зацепка + внешний фактор для отступления (тактический выход).
- **Нецелевой 15%** — клинической зацепки нет в принципе, эталон = выход с переключением на целевого пациента.
- Цель распределения — научить распознавать нецелевых пациентов, но не превращать уход в отмазку.

### Обязательная ротация подтипов
- ~1 из 5 целевых кейсов на Конкор АМ — стенокардия III-IV ФК (по КР МЗ РФ: стартовая комбинация БАБ + ДГП-БКК для достижения ФК I).
- Не менее 1 из 4 целевых — тип Б2 (пациент уже на бисопрололе + амлодипине раздельно → объединение в Конкор АМ).

### Стилистические ограничения
- Нельзя: «метаболически нейтрален» (не в инструкции), «субдиуретическая доза» (не в инструкции), «88% достигают 10 мг» (искажение Terol 1990 — правильно «88% хорошо переносили»).
- Можно: короткие корпоративные формулировки 75% / 16% (с возможной ссылкой на Григорьеву 2010 / Tian 2020).
- Запрет на технические коды типологии (А1–А4, Б1–Б4, В1–В10, Г1–Г7) в речи медпреда.
- Запрет на номер кейса в Фазе 1.
- Запрет на раскрытие категории кейса до Фазы 2.

### Конкор НСТ — правило коморбидности
- ✅ Разрешён при АГ + ИБС / АГ + ФП (показание — АГ, коморбидность лечится отдельно/попутно).
- ❌ Запрещён при ИБС или ФП без АГ.
- ❌ Запрещён при ХСН.

### Изолированная АГ — приоритеты для Конкор АМ
- Целевые кейсы Конкор АМ — только АГ + ИБС (основной портрет).
- Изолированная АГ → для Конкор АМ только пограничный (клинически возможно, не профильно для генератора).
- Изолированная АГ + тахикардия → целевой для Конкор-монотерапии, не для Конкор АМ.

### Точные цитаты КР МЗ РФ
- АГ 2024, стр. 10: «ББ — один из пяти основных классов АГП. Предпочтительными ситуациями для их назначения являются... контроль ЧСС».
- АГ 2024, стр. 22: «ЧСС >80 в минуту — независимый фактор сердечно-сосудистого риска».
- Стабильная ИБС 2024: «При стабильной стенокардии I-II ФК и ЧСС >60 уд/мин рекомендуется... для снижения ЧСС до значений 55-60 уд/мин» (ЕОК I A, УУР А, УДД 5).
- Стабильная ИБС 2024: «При стабильной стенокардии III-IV ФК при отсутствии противопоказаний рекомендуется сразу назначить комбинацию БАБ с ДГП-БКК для достижения ФК I» (ЕОК I C, УУР C, УДД 5).

### Технические артефакты, использованные в работе
- **Claude Opus 4.7** — архитектура, итеративная разработка.
- **Claude Code** — анализ ~600 страниц клинреков и инструкций, извлечение базы знаний.
- **Claude Design** — визуальная подача (запущен 17 апреля 2026).
- **Merck myGPT Suite (Langdock, Sonnet 4.6)** — развёртывание агентов.
