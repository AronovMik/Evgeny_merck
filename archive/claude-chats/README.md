# archive/claude-chats

Перенесённые чаты из claude.ai (вручную, поскольку прямого экспорта в репозиторий нет).

> **Индекс:** [`PREVIOUS_CHATS.md`](./PREVIOUS_CHATS.md) — короткие описания всех чатов в этой папке, для быстрого решения «нужен ли этот чат как контекст сейчас». Сами чаты подгружаются только по команде пользователя.

**Конвенция именования:** `YYYY-MM-DD_тема.md`. Если точная дата неизвестна — `YYYY-MM_тема.md` или `undated_тема.md`.

**Структура файла:**
```
# Тема чата

**Дата:** YYYY-MM-DD (или приблизительно)
**Контекст:** короткое описание задачи/проекта Claude, к которому относился чат
**Препарат/тема:** Конкор / Конкор АМ / Конкор НСТ / общее

---

## Запрос
<текст моего запроса>

## Ответ
<ответ Claude>

## Дальнейшие сообщения
<если был диалог>
```

Чтобы перенести чат: вставьте его содержимое в следующем сообщении, я создам файл в этой папке по конвенции **и добавлю запись в `PREVIOUS_CHATS.md`**.
