# Evgeny — Merck Russia, Cardiology

Рабочий репозиторий для подготовки медицинских материалов по портфелю Конкор (бисопролол, бисопролол + амлодипин, бисопролол + гидрохлортиазид) и смежным задачам в кардиологии.

## Навигация

- **[INSTRUCTIONS.md](./INSTRUCTIONS.md)** — поведенческие правила, верификация источников, комплаенс. Применяются всегда.
- **[CLAUDE.md](./CLAUDE.md)** — контекст для Claude Code (структура, конвенции файлов).
- **tasks/** — задачи, сгруппированные по типу выхода (слайды, письма, ответы KOL, анализы, сравнения, научные тексты).
- **context/** — справочные материалы: клинические рекомендации, инструкции по применению, ключевые исследования, портфельное позиционирование.
- **archive/claude-chats/** — перенесённые чаты из claude.ai (вручную).
- **templates/** — шаблоны под повторяющиеся форматы.

## Конвенция именования файлов

`YYYY-MM-DD_препарат_короткое-описание.md`

Примеры:
- `2026-05-17_konkor-am_kol-response-amlodipine-edema.md`
- `2026-05-17_konkor-nst_slides-fdc-rationale.md`

## Workflow для новой задачи

1. Определить тип задачи → подпапка в `tasks/`.
2. Создать файл по конвенции именования.
3. Прочитать релевантный контекст из `context/`.
4. Подготовить материал по чеклисту из `INSTRUCTIONS.md` (Блок 3).
5. Указать источники в конце файла (PMID/DOI).
6. Коммит с описательным сообщением.
