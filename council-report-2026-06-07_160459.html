Принимает ли команда Клинический кейс №3 — пациентка 63 года, АГ + стабильная стенокардия ФК III + ХБП С3bА2 + концентрическая ГЛЖ; маршрут «подбор доз на свободных компонентах → перевод на Конкор АМ 10/10» — для позиционирования с тремя акцентами (почечная безопасность бисопролола, приверженность через FDC, оригинальный бренд Конкор vs дженерики)?

Вердикт председателя

Где совет соглашается. Подмена РААС-блокатора — критическая ошибка. «Оригинальный Конкор vs дженерики» и «согласуется с когортными исследованиями» — без источников, требуют backing.
Где совет расходится. Диастолическая дисфункция — оставить с добавлением E/A vs убрать. ЧСС 66 — оправданная посадка vs недостижение цели.
Голос и peer review. 2 из 3 reviewers — самый сильный Маркетолог; все 3 — самое большое слепое пятно Кардиолог 1 (принял ЧСС 66 без источника — ровно та же логика, которую критикует у авторов).
КРИТИЧНО — без этого кейс не выходит:
  1. РААС-блокатор: оставить периндоприл 8 (как в Слайде 2), убрать рамиприл из Шага 1.
  2. «Оригинальный Конкор vs дженерики» — добавить конкретный источник или убрать тезис.
  3. «Согласуется с когортными исследованиями» — PMID/DOI (вероятно Verma 2018) или убрать.
ВАЖНО — для устойчивости:
  1. Доза при С3b: «допустима 10 мг при С3b» → «коррекция дозы бисопролола при ХБП С3b не требуется — ограничение «не выше 10 мг» относится только к тяжёлой ХПН (КК <20 мл/мин) по ОХЛП Конкор». Точнее и сильнее.
  2. Диастолическая дисфункция: добавить E/A и E/e' в ЭхоКГ, либо убрать из диагноза. Рекомендация: убрать (не работает на позиционирование).
  3. ЧСС 66: «целевой коридор 55–60 не достигнут; индивидуальная переносимость ограничивает дальнейшую титрацию при ФК I и ХБП С3b». Без маскировки.
  4. Шаг 1 — два одновременных изменения (бисопролол-дженерик → Конкор + 5→10): разнести на 2 микро-шага, либо явно прокомментировать как единое решение по приверженности и предсказуемости.
  5. Грамматика и регистр: «Дислипидемия достигнут» → «ХС-ЛНП достигнут»; «вечерний амло — миф» → «время приёма амлодипина не имеет клинического значения (t½ 35–50 ч)»; «бисо» при первом упоминании раскрыть.
Опционально: «Стресс-ЭхоКГ: объём ишемии умеренный» — «объём» уточнить (зона ишемии умеренная по числу затронутых сегментов).
Сделать первым: правка РААС-блокатора + два compliance-источника (1 + 2 + 3). Один сжатый проход снимает критический блок и обе compliance-уязвимости.

Ответы участников

Кардиолог 1 (защита) — ПРИНЯТЬ с правками
Кейс клинически состоятелен; типичный для российской поликлиники профиль. ИМТ 22,8, без СД, ХБП как следствие АГ — согласованный анамнез. Построчно в пользу: - ГЛЖ подтверждена двумя методами (Соколов-Лайон 38; ИММЛЖ 118 с ОТС 0,48). - Локальная сократимость — только по стресс-ЭхоКГ. - ИБС ФК III: 200–300 м + 1 пролёт — прямой критерий ФК III по CCS. - СКФ 36 + А/К 80: стадия и альбуминурия совпадают. - Решение ОМТ vs КАГ обосновано. - АД ≤130/80 при ХБП достигнут. Ответы на VF: - Подмена РААС: правка 3 слов, логику не меняет. - DD I без E/A: концентрическая ГЛЖ патофизиологически неотделима от DD I; E/A и E/e' добавить. - ЧСС 66 при ФК I + ХБП — оправданная посадка; fair balance закрывает. Итог: принять с правкой РААС-блокатора + желательно E/A.
Кардиолог 2 (оппонент) — НЕ ПРИНИМАТЬ
Построчные находки: - Подмена РААС-блокатора — критическая ошибка перед подготовленным кардиологом. - DD I без верификации: по ASE/EACVI 2016 — минимум 2 из 4 критериев; нет E/A, E/e', TR; «ЛП в норме» противоречит DD I. - ЧСС 66 — выход за 55–60; «контролируемый диапазон» без источника — введение в заблуждение. - Стресс-ЭхоКГ «объём умеренный» — двойное прочтение. - USP «оригинал vs дженерики» и «когортные» — без ссылок. - Шаг 1: одновременное повышение бисо 5→10 + (возможно) смена ИАПФ за 7 дней — нельзя атрибутировать эффект. Вопросы аудитории: почему периндоприл в рамиприл? на чём DD I? цель ЧСС достигнута? какие когортные? что дало эффект на Шаге 1? Итог: критическая ошибка + невалидированная DD + два неподкреплённых USP + некорректная подача ЧСС 66. Не выдержит разбора.
Маркетолог Merck (guardian) — С ПРАВКАМИ (compliance)
Off-label-вахта + регуляторно-маркетинговые находки: - «Допустима 10 мг при С3b» имплицирует ограничение, которого нет → «коррекция не требуется (ОХЛП: ограничение только при КК <20)». - КРАСНЫЙ ФЛАГ: «Оригинал vs дженерики» — без backing-источника (ФЗ-38 ст. 24). - КРАСНЫЙ ФЛАГ 2: «согласуется с когортными» — PMID/DOI обязательны. - Подмена РААС — флаг небрежности (зона кардиологов). - Off-label по показаниям нет: АГ + ИБС в рамках 4.1 (с дисклеймером на мастер-слайде). USP-блок: - Видимость продукта удовлетворительная. - Уникальность частичная: почечная безопасность работает автономно; «оригинал vs дженерики» без цитирования — слабейший USP. - Тоннель внимания: DD I не работает на позиционирование, кандидат на удаление. - Дрейф: правильно — заканчивается USP + fair balance. Небрежность-сторож: - «Дислипидемия достигнут» — ошибка согласования рода. - «вечерний амло — миф» — разговорный регистр. - «бисо» без раскрытия. Итог: 2 compliance-блокера + переформулировка по С3b + небрежности. С обязательными правками — принимаем.
