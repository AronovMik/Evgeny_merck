# ideas/

Банка идей. Два уровня:

1. **`INBOX.md`** — поток сырых идей в свободной форме. Append-only. Пишется без структурирования, чтобы не терять мысли.
2. **`<topic>.md`** — отдельный файл, когда идея созрела до самостоятельной темы и требует развития (несколько подпунктов, ссылки, открытые вопросы). Создаётся вручную, когда понятно, что идея «выросла» из строки в INBOX.

**Когда переводить из ideas/ дальше:**
- Идея стала конкретным действием → `TODO.md`.
- Идея стала рабочей задачей с дедлайном/результатом → файл в `tasks/`.
- Идея стала принятым принципом/политикой → `decisions/`.
