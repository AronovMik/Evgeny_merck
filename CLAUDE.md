Полный свод правил поведения, верификации источников, комплаенс-ограничений и приоритизации — в @INSTRUCTIONS.md. Применять во всех задачах без исключения.

## Контекст проекта

Репозиторий федерального медицинского советника Merck Russia (кардиология). Используется для подготовки материалов по портфелю β-блокаторов (Конкор, Конкор АМ, Конкор НСТ) и для других медицинских/научных задач.

**Портфель Конкор:**
- **Конкор** — бисопролол (β1-селективный адреноблокатор).
- **Конкор АМ** — фиксированная комбинация: бисопролол + амлодипин.
- **Конкор НСТ** — фиксированная комбинация: бисопролол + гидрохлортиазид 6.25 мг.

Инструкции написаны под более широкий портфель (включают упоминания SGLT2-ингибиторов / канаглифлозина) — это не ошибка, они универсальны для всех задач Евгения, не только Конкор.

## Структура репозитория

```
tasks/              задачи по типу выхода
  slides/           слайды, презентации
  letters/          письма (KOL, врачам, внутренние)
  kol-responses/    ответы на вопросы KOL
  analyses/         аналитические справки
  comparisons/      сравнительные таблицы, head-to-head, NMA
  scientific-texts/ научные тексты, абстракты, обзоры

context/            справочные материалы (читать перед задачей)
  guidelines/       клинические рекомендации (ESC, РКО, AHA/ACC, ESH)
  product-info/     инструкции по применению, ОХЛП, локальные SmPC
  key-studies/      ключевые публикации (CIBIS-II, и др.)
  portfolio/        позиционирование портфеля

archive/
  claude-chats/     перенесённые чаты из claude.ai

templates/          шаблоны под повторяющиеся форматы
```

## Рабочие принципы для этого репозитория

1. **Каждая задача — отдельный файл** в соответствующей подпапке `tasks/`. Именование: `YYYY-MM-DD_короткое-описание.md`.
2. **Используемые источники** перечислять в конце файла задачи (PMID/DOI), даже если они уже лежат в `context/key-studies/`.
3. **Препарат-специфика**: при подготовке материалов для конкретного препарата явно указывать его в заголовке файла (Конкор / Конкор АМ / Конкор НСТ).
4. **Off-label и непрямые сравнения** маркировать в тексте, а не только в комментарии (см. Блок 5 INSTRUCTIONS.md).
